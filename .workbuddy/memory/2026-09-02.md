### 修复 "Hermes couldn't start / Could not connect to Hermes gateway"(14:36)
- **根因**:浏览器 WS 握手带 `Origin: https://xinyejianqianshenqi.cn`,nginx 原样转发给绑定 `127.0.0.1` 的后端,后端 origin/host 校验拒绝,握手直接 403 → 前端报 gateway 连不上
- **复现**:curl 带 `Origin` 头请求 `/hermes/api/ws` → 403;不带 Origin → 101 + `gateway.ready`
- **修复**:在 `/www/server/nginx/conf/vhost/hermes-desktop-web.inc` 的 `/hermes/api/ws` location 增加 `proxy_set_header Origin "";`,nginx `-t` + reload
- **验证**:修改后 curl 带浏览器 Origin 头 → 101 + gateway.ready,问题解决
