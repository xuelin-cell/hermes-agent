这是一套"先立设计哲学（美学运动），再把它视觉化表达"的方法。输出只产 `.md`（哲学）、`.pdf`、`.png` 三种文件，全部写入当前工作目录（workspace）。

分两步完成：
1. 设计哲学创作（`.md` 文件）
2. 在画布上表达它（`.pdf` 或 `.png` 文件）

---

## 第一步：设计哲学创作

先创作一个**视觉哲学**（不是版式或模板），它将通过以下维度被诠释：形与空间、色彩、构图、图形/形状/图案、作为视觉点缀的极少文字。

### 关键理解
- **收到的**：用户给的一点点微妙输入/意图，作为地基而非枷锁，不该束缚创作自由。
- **创造的**：一套设计哲学 / 美学运动。
- **接下来**：同一个你拿着这份哲学，把它**视觉化表达**——产出 90% 视觉、10% 必要文字的作品。

哲学要强调：视觉表达、空间沟通、艺术诠释、极简文字。

### 怎么生成一个视觉哲学
**给运动命名**（1–2 词）："野兽派之欢" / "色度沉默" / "代谢派之梦"

**阐述哲学**（4–6 段，凝练而完整），从这些维度表达它如何显现：空间与形、色彩与材质、尺度与节奏、构图与平衡、视觉层级。

**关键准则：**
- **避免重复**：每个设计维度只讲一次，别反复念叨色彩理论/空间关系。
- **反复强调工匠精神**：哲学必须多次强调最终作品要看起来"耗费了无数心血、被精心打磨、出自领域顶尖之手"——重复"精雕细琢""深厚功力的产物""极致用心""大师级执行"这类措辞。这一点是本质。
- **留出创作空间**：方向要具体，但要凝练到让下一步的表达仍有极高水准的诠释余地。

哲学要引导下一步用**视觉**而非文字表达思想。信息活在设计里，不在段落里。

（原技能附有 "Concrete Poetry" / "Chromatic Language" / "Analog Meditation" / "Organic Systems" / "Geometric Silence" 等浓缩范例，实际写时展开成 4–6 段。保持哲学通用、不点破作品意图，仿佛可用于任何场合。输出为一个 `.md` 文件。）

## 第二步：推演那条"微妙的引用"

**关键步骤**：动手画布之前，从原始需求里识别出那条微妙的概念线索。作品的主题应作为**一条微妙、小众的引用嵌入艺术本身**——不必字面、始终高级。懂的人会心一笑，不懂的人也只是欣赏一幅大师级抽象构图。设计哲学提供美学语言，被推演出的主题提供灵魂——那条无形织入形、色、构图的概念 DNA。像爵士乐手引用另一首曲子：识者会心，众人皆赏。

## 第三步：画布创作

用第一步的哲学作地基，创作**一整页、高度视觉化、以设计为先**的 PDF 或 PNG（除非要求多页）。追求美术馆/杂志级品质：善用重复图案与完美形状；把抽象哲学设计当作"科学圣经"来对待，借用系统观察的视觉语言——密集的标记堆叠、重复元素、层叠图案，通过耐心重复积累意义、经得起反复端详。加入稀疏、临床般的排版与系统化的参考标记，仿佛出自某个想象学科的图谱。用一句话或细节作锚点、subtle 地摆放，配一套克制而统一的有限色板。

**文字作为语境元素**：文字始终极简、视觉优先，但让语境决定它是"耳语般的小标签"还是"大胆的排版姿态"——朋克演出海报的字可以更大更冲，极简陶艺工作室的标识则更安静。字重多数偏细。无论字号，**任何文字/图形都不能掉出画面、不能重叠**，每个元素都要有留白与清晰间隔——这是专业执行的底线，不可妥协。

**字体（重要）**：写字时用不同字体，搜 `./canvas-fonts` 目录（本技能精选了 15 个西文字族：BigShoulders/Gloock/Boldonse/Italiana 等展示体，CrimsonPro/IBMPlexSerif/YoungSerif 衬线，InstrumentSans/WorkSans/Outfit/BricolageGrotesque 无衬线，JetBrains/IBMPlexMono 等宽，Silkscreen/NothingYouCouldDo 点缀）。让排版成为艺术本身的一部分——抽象作品就把字"画"进画布，而非机械排字。

### ⚠️ 先分清：信息型海报 vs 艺术型海报（实测微调，别用错哲学）

本技能的"极简文字、90% 视觉"哲学是给**艺术/展览/氛围型**作品的（摄影展、品牌意象、诗意主题）。但很多真实需求是**信息型海报**（招聘、活动、促销、赛事），**文字本身就是主角**——岗位、时间地点、报名方式、规则、联系方式一个都不能少。

- **信息型海报**：先保证**所有功能信息完整、清晰、有层级**，再谈美学。绝不能为了极简把关键信息删掉或压成读不清的小字（实测教训：招聘海报被极简成一个黑块、岗位和邮箱全丢=失败）。美学服务于"让人一眼看懂并行动"。
- **艺术型海报**：才放开用极简文字 + 强视觉那套。
- 拿不准就问一句，或按"信息完整优先"稳妥处理。判断信号：需求里有**具体日期/价格/岗位/报名入口/规则**→信息型；只有一个主题词/情绪→艺术型。

### 📐 单文件海报模式（当只要一张 HTML/PNG 海报时）
若任务是"直接产一张海报"（不是两步 philosophy+canvas 流程），**产物文件里只放海报本身**：把设计思路留在你的思考里，**绝不把"设计说明/亮点/思路"写进 HTML**（会当正文渲染出来，翻车）。画布**固定尺寸**（如 1080×1350）用一个居中容器承载，所有元素绝对定位或用 flex/grid 约束在画布内，**任何文字/图形不许溢出画布边界**；渲染后逐个检查无溢出、无裁切、无重叠再交付。

### 🔧 UniClaw 内置工具（别只用 CSS 画形状）
需要真实照片/产品图/品牌 logo 作主视觉时，用**联网搜索**（bocha，结果含图片 `contentUrl`）或 **UniAI-Toolkit MCP** 取真实图片；需要独特氛围图/纹理且搜不到时用**图生图**。纯 CSS 几何形状是一种风格，但真实影像往往更有质感——别默认只画色块。成品用 playwright/系统 Edge 无头**截图自检**再交付。

### ⚠️ 中文作品必读：CJK 字体
`./canvas-fonts` 里**全是西文字体，没有中文**。做中文海报/封面时，中文字符必须用系统 CJK 字体，否则渲染成方框/空白：
- **Windows(Lite)**：`C:/Windows/Fonts/` 下的 `msyh.ttc`(微软雅黑) `msyhbd.ttc`(粗) `simhei.ttf`(黑体) `simsun.ttc`(宋体) `STXINWEI.TTF`(华文新魏) 等。
- **Linux/macOS(Pro)**：`Noto Sans SC` / `Source Han Sans` / `PingFang SC`，装的话在 `/usr/share/fonts` 或 `~/.fonts`。
- 中文标题追求气势用黑体/思源黑体粗，文艺气质用宋体/思源宋体或书法体；中英混排时西文用 canvas-fonts 里的字族、中文用 CJK 字体，各自单独指定。

### 落地渲染路径（具体做法）
把构图当成一张 HTML/SVG 页来精确排布，再用无头浏览器高保真渲染成图片（对字体、渐变、混合模式支持最好，也最可控）：
```bash
# 1) 写 poster.html（内联所有 @font-face 指向 canvas-fonts / 系统 CJK 字体，画布固定尺寸如 1080×1920）
# 2) 无头渲染成 PNG（设 deviceScaleFactor 提高清晰度）
python -c "from playwright.sync_api import sync_playwright
with sync_playwright() as p:
    b=p.chromium.launch(); pg=b.new_page(viewport={'width':1080,'height':1920}, device_scale_factor=2)
    pg.goto('file:///绝对路径/poster.html'); pg.wait_for_timeout(600)
    pg.screenshot(path='poster.png'); b.close()"
# 需要 PDF：pg.pdf(path='poster.pdf')（仅 chromium headless 支持），或 PNG 转 PDF
```
矢量/程序化图形也可用 Python（matplotlib/PIL/svglib+reportlab），但 HTML/SVG 路线对排版与视觉细节控制最强。

**关键**：要达到"人类精心创作"而非"AI 生成"的质感，做出看起来耗费无数心血、由顶尖高手对每个细节精雕细琢的作品。反复检查：无重叠、格式无瑕、每个细节完美。

## 最终一步（打磨）

**用户已经说了**："还不够完美。它必须是无瑕的、一件工匠精神的杰作，仿佛即将在美术馆展出。"

**关键**：打磨时**别加更多图形**；而是精修已有的、让它极度清爽，完全尊重设计哲学与极简原则。与其加滤镜或换字体，不如思考如何让现有构图与艺术更浑然一体。若冲动是"再画个新形状/调个新函数"，**停下**，改问："我怎么把已经在这儿的东西，做得更像一件艺术品？"回到代码，再精修一遍。

## 多页选项
需要多页时，沿同一设计哲学创作更多页、但又各具鲜明差异，打包进同一个 `.pdf` 或多张 `.png`。把第一页当作一整本咖啡桌画册里的一页，后续页是原作的独特变奏与回响，以极有品味的方式几乎讲出一个故事。充分发挥创作自由。
