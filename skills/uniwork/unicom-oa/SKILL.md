## 四条铁律

### 1. ⛔ 城市选择：禁止输入，只能点击选择

```
┌─────────────────────────────────────────────────────────────────┐
│  绝对禁止：在任何输入框输入城市名称                               │
│                                                                 │
│  城市输入框不是文本框！不能输入！                                │
│  弹窗内的搜索框也不可靠！禁止输入搜索！                          │
└─────────────────────────────────────────────────────────────────┘

正确流程：
1. 点击城市输入框尾部的「搜索图标」
2. 等待城市选择弹窗出现
3. 点击「常用城市」或「拼音开头」模块
4. 在展开的列表中点击目标城市

❌ 错误：browser_type 在城市输入框输入城市名
❌ 错误：browser_type 在弹窗搜索框输入搜索
✅ 正确：browser_click 搜索图标 → browser_click 常用城市/拼音 → browser_click 城市名
```

### 2. 应用发现：首页没有就点"应用管理"

```
首页搜索框搜的是新闻，不是应用！

首页有目标应用 → 直接点击
首页没有 → 点击首页左侧"应用管理"按钮 → 在应用中心搜索
```

### 3. 商旅身份：必须询问用户

```
进入商旅服务弹出身份选择时，必须用 AskUserQuestion 询问用户选哪个身份。
禁止默认选择主岗！
```

### 4. 事后补单：必须点击"是"或"否"

```
选择业务类别后，必须显式点击"是"或"否"选项，不能跳过！
操作顺序：选业务类别 → 点击"否"或"是" → 点商旅申请
```

## ⛔ 商旅申请强制 TodoList

当用户要求提交差旅申请时，必须使用 TodoList 规划任务列表，并确保规划里有包含以下检查项：

```
任务：提交差旅申请

必须包含的检查项：
□ 添加计划行程 - 城市选择检查：
  - 出发城市：点击搜索图标 → 弹窗 → 点击常用城市/拼音模块 → 选择城市
  - 到达城市：点击搜索图标 → 弹窗 → 点击常用城市/拼音模块 → 选择城市
  - 确认城市已正确填入输入框（不是手动输入的无效值）
```

**城市选择验证标准：**
- ✅ 正确：输入框显示的城市是通过点击搜索图标 → 弹窗 → 选择得到的
- ❌ 错误：输入框显示的城市是直接输入的（无效，系统不识别）
- 如果城市未正确填入，必须重新按正确流程选择

## 登录流程

1. 打开网址，切换"短信登录"
2. 填手机号，点"获取验证码"，询问用户验证码
3. 填验证码，点登录，关闭可能弹出的"每周微学"

## 应用发现流程

**首页搜索框搜的是新闻，不是应用！**

```
登录成功 → 获取首页快照 → 检查首页常用应用
                                │
                ┌───────────────┴───────────────┐
                ▼                               ▼
          找到目标应用                    未找到目标应用
                │                               │
          点击进入                    点击首页"应用管理"按钮
                                              │
                                    在应用中心搜索/查找
```

应用中心操作：
1. 点击首页"应用管理"进入应用中心
2. 查找应用：优先查"最近使用"，其次用搜索框
3. 编辑模式：点击应用 → 弹菜单 → 点"了解应用" → 点"进入应用"
4. 非编辑模式：直接点击或进详情页点"进入应用"
5. 切换到新标签页继续操作

## 商旅服务

### 进入

1. 按应用发现流程找到"商旅服务"
2. **身份选择必须用 AskUserQuestion 询问用户，禁止默认选主岗**
3. 关闭可能的通知弹窗

### 新建商旅单

点击"+商旅申请"按钮弹出对话框：

**业务类别**：下拉选择，常见：部门差旅费-业务部门、部门差旅费-管理部门、研发差旅费-费用化支出

**是否事后补单**：必须显式点击"是"或"否"，不能跳过！

```
操作顺序：选择业务类别 → 点击"否"或"是" → 点击"商旅申请"按钮
```

### 添加计划行程

**⛔ 城市选择：禁止输入，只能点击选择**

```
┌─────────────────────────────────────────────────────────────────┐
│  绝对禁止：在任何输入框输入城市名称                               │
│                                                                 │
│  城市输入框不是文本框！不能输入！                                │
│  弹窗内的搜索框也不可靠！禁止输入搜索！                          │
└─────────────────────────────────────────────────────────────────┘
```

正确流程（只能用 browser_click）：
1. `browser_click` 城市输入框尾部的「搜索图标」
2. `browser_snapshot` 确认城市选择弹窗已出现
3. `browser_click` 「常用城市」或「拼音开头」模块
4. `browser_click` 列表中的目标城市
5. 弹窗关闭，城市自动填入

**验证城市是否正确填入：**
- 使用 `browser_snapshot` 检查输入框状态
- 如果输入框为空或显示无效值，重新按流程选择
- 只有通过弹窗选择的城市才是有效的

禁止操作：
- ❌ `browser_type` 在城市输入框输入城市名（无效！）
- ❌ `browser_type` 在弹窗搜索框输入搜索（选中不可靠！）

**其他字段**：日期选择器、交通工具下拉、生成返程勾选

### 后续操作

- 商旅单详情页：修改行程、添加人员、上传附件
- 提交审批：选择下一环节和处理人
- 创建前需绑定银行卡，若提示未绑定则引导用户绑定
