# 输出与过滤规则

## 下载文件交付

下载启动后必须调用 `VideoDownloadJob.register`，由后台管理器在完成时验证文件、复制 VM/云端成品并生成原会话附件卡片。登记成功后 Skill 不再等待或调用 `PresentToUser` 重复交付。

仅在启动回复中展示本地路径不代表任务已经完成；最终结果以原会话中的后台任务结果卡片为准。

## 先排除

验证之前就该丢掉的：

- 付费平台：`v.qq.com`、`iqiyi.com`，除非明确免费/限免。
- 搜索聚合页：`sogou.com`、`so.com`、`baidu.com`（`pan.baidu.com` 除外）。
- 非视频站：`jianshu.com`、`zhihu.com`、`douban.com`、`weibo.com`、`csdn.net`、`sohu.com`、`163.com`、`sina.com.cn`。
- 文章路径：`/p/数字`、`/a/数字`、`/news/`、`/article/`。

## 优先级分层

按**站点特征**分层，不是靠一份写死的站点名单——名单会过期，特征不会：

1. **P1 本次会话已验证可播**：`probe_media.py` 判定 pass 的源。自己验过的最可信。
2. **P2 网盘**：`pan.quark.cn`、`pan.baidu.com`。用户转存即可，不用管 m3u8 能不能播。
3. **P3 疑似点播站**：路径含 `/vod`、`/play`、`/video`、`/detail`、`/ep`，或域名含 `dy`、`tv`、`vod`、`play`。
4. **P4 官方平台**：`bilibili.com`、`youku.com`、`mgtv.com`。要严格验证是否真的免费。

## 正版入口

分层只决定"免费可看"这一组怎么排，不代表正版平台不该出现。**片子在正版平台有授权版本时，在结果末尾单列一行给出正版入口**（写明需要会员就写明），比如：

```markdown
### 正版观看
《狂飙》在 [爱奇艺](https://www.iqiyi.com/...)（需会员）有正版全集。
```

这一行成本极低：不挤占免费结果，用户想支持正版时有路可走，工具本身的位置也更稳妥。不确定是否真有授权版本就别写，宁可不给也不要给错的正版链接。

## 页面门槛

两条都要过：

1. 标题或首段包含核心片名关键词。
2. 页面有播放特征：`播放`、`在线观看`、`剧集`、`第X集`、`m3u8`、`.mp4`、`player`、`dplayer`、`ckplayer`、`vod`、`play`、`1080P`、`4K`。

付费墙特征：`VIP`、`会员`、`付费`、`购买`、`订阅`、`试看`、`需会员`、`点播`。注意 `VIP免费` 仍然是要 VIP。

## 链接格式

播放地址必须是 Markdown 可点击链接。用户要的是能直接点开的东西，纯文本 URL 得手动复制粘贴，反引号包裹的更是点不动。

错：

```markdown
| 360资源 | https://vod.example.com/index.m3u8 |
| 360资源 | `https://vod.example.com/index.m3u8` |
```

对：

```markdown
| 360资源 | [播放链接](https://vod.example.com/index.m3u8) |
| 第01集 | [m3u8](https://vod.example.com/ep01/index.m3u8) |
```

## 连续剧输出

有全集就先给全集：

```markdown
## 《{片名}》片源搜索结果

### 免费可看
| 站点 | 清晰度 | 验证状态 | 播放页 |
|---|---|---|---|
| 示例影院 | 1080P | ✅ 全39集m3u8已提取，抽检第1/20/39集均可访问 | [第1集播放页](https://...) |

### 全集直链列表
| 集数 | m3u8/mp4 链接 |
|---|---|
| 第1集 | [m3u8](https://.../index.m3u8) |
| 第2集 | [m3u8](https://.../index.m3u8) |
```

只找到一集时放进"不确定"分组，并写明 `仅单集，未满足全集目标`。把单集说成全集是用户最容易感到被骗的地方。

## 组内排序

1. `probe_media.py` 抽样拉流成功（`--sample`）。
2. 探测拿到合理时长。
3. 页面验证通过。
4. P1 / P2 / P3 / P4。
5. 真实分辨率、码率、体积。

被排除的结果不要出现在推荐里。
