## P08 · 加密保存完整登录记录

2026-10-03 已接入 `electron/login/credential-store.ts`。固定应用级目录下的 `maas-login.enc` 保存一份完整密文，包含平台身份域 `maas.ai-yuanjing.com/uniwork`、UID、token、有效期和脱敏手机号；不保存完整手机号或短信码。生产路径默认是 `%APPDATA%\HermesDesktopMT\maas-login.enc`，测试沿用既有独立 `userData` 覆盖机制。

通过 Electron `safeStorage` 加密，复用已有 `writeSecretFileAtomic` 先写同目录临时文件再原子替换；与原版远程连接的可选明文开关无关。系统加密不可用、加密异常或文件替换失败时，登录不完成，不留下进程内身份，不以明文或只在内存保存作为回退。替换失败保留旧正式记录；遗留的临时文件也只含密文，下次保存由既有写入工具清理。

读取方法只供主进程使用，区分文件不存在与读取／解密／字段失败；失败不改写原文件，不把错误细节传给页面。解密后再次校验平台身份域和全部字段。读取到已经过期的结构合法记录，不代表允许恢复登录。P08 当时只接入存储；当前启动流程按下述 P09 恢复未到期身份。

验证：18 项定向测试通过；整组 Electron 检查 5 项通过、1 项真实 MaaS 取图默认跳过。真实 Windows 夹具完成写入失败拒绝登录、成功加密落盘、关闭旧进程、用同一目录启动新进程并解密出相同完整记录，同时确认页面没有自动恢复身份。损坏密文与明文冒充记录均被拒绝，失败文件保留，未启动 Hermes 或创建账号 Home。实际登录请求仍使用受控响应，不消费真实短信码；系统加密和文件读写没有替换为模拟实现。完整 TypeScript、相关 ESLint（零警告）和 `git diff --check` 通过。

人工验收：沿用当前源码启动入口完成真实短信登录后，固定目录应出现 `maas-login.enc`；当前关闭重开的行为按 P09 执行。不要将密文文件、实际 token 或模型 Key 粘贴到聊天中。

- 提交主题：`feat(login): 加密保存账号登录记录`。

## P09 · 从未到期的本地记录恢复身份

2026-10-03 按用户确认的四步规则接入。主进程复用 P08 的完整记录解密与字段校验，期限仍在未来才恢复原 UID、token 和有效期；无记录、读取／解密／字段错误或到期，返回未登录。恢复不请求网络、不改写记录、不延长期限，也不删除用户数据。

登录页先等待受限 `restore()` IPC，再显示账号卡片或登录表单。有效记录不会先显示表单、请求验证码或再次提交短信登录。页面仍只得到脱敏手机号和有效期；到期恢复空表单。其他窗口、子框架、错误地址和带额外参数的调用不能恢复身份。

验证：22 项定向测试通过；真实 Electron 检查 5 项通过、1 项真实 MaaS 取图默认跳过。跨进程恢复、过期与坏记录拒绝使用实际 Windows 系统加密和文件读写，MaaS 登录响应受控；有效恢复没有网络请求，失败未修改记录或旧连接文件，也未启动 Hermes。完整 TypeScript、相关 ESLint（零警告）及 `git diff --check` 通过，并检查了恢复后的账号卡片截图。真实短信登录和账号环境尚未人工验收。

- 提交主题：`feat(login): 恢复未到期的本地账号`。
- 自动检查：有效身份原值复用、无记录、读取失败、到期、恢复期间不请求验证码、失败后表单可用、并发登录与关闭后的恢复拒绝。
- 真实验收：同一临时目录与 Windows 用户，关闭旧 Electron 并启动新进程；实际系统加密记录恢复原身份。过期密文、损坏密文和明文冒充记录分别重开，要求登录且原文件保留。
- 人工验收：用户完成真实短信登录后，关闭重开看到同一脱敏账号；实际上游字段及账号环境仍分别按 P07 与阶段二验收。
- 边界：本步恢复的是身份，不启动 Hermes、不创建账号目录。按 UID 打开原环境由 P11～P17 接入；套餐由 P10 单独查询，无套餐或查询失败不取消身份与自定义模型能力。

## P10 · 套餐获取与模型信息解析

2026-10-03 已接入 `electron/login/plan.ts`、`LoginSession.queryPlan()`、受限 `plan()` IPC 与独立 `PlanStatus` 展示组件。短信登录或恢复成功后，页面单独查询套餐；登录成功不等待查询完成。有套餐展示模型名称与默认标记；无套餐展示明确说明；查询失败允许手动重试，不取消账号身份。仍保留原版自定义模型能力，本步没有写入或删除任何模型配置。

主进程使用自己的登录 token 请求固定 `my-plan` 地址，15 秒超时、不跟随跳转、不自动重试。并发查询合并；到期或关闭后的迟到结果不能放行或保留套餐。模型 Key 与完整目录只保存在主进程内存，新增 IPC 仅返回查询状态、模型名称和默认标记，不返回 Key、端点或原始响应。查询失败不清除已有成功套餐；显式空套餐清除本进程套餐，但不清除身份或用户配置。
