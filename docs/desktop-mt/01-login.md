## P06 · 短信发送与倒计时

2026-10-03 已接入 `electron/login/sms.ts` 与受限 `sendSms` IPC，页面通过 `use-sms.ts` 管理发送状态。手机号、图片码和图片 ID 在主进程再次校验，只发送三个必要字段；固定上游、15 秒超时、不自动重试，也不记录手机号或验证码。

页面和主进程分别拦截并发请求。成功后冷却 60 秒，主进程保存期限，因此刷新页面或修改手机号不能绕过本窗口内的冷却；重新点击时页面会收到剩余期限。倒计时按截止时间计算，窗口挂起后不会继续显示旧秒数。此保护不跨应用重启持久化，上游仍负责实际发码限流。

普通失败不开始倒计时，用户可以修正输入、点击图片刷新后重试。HTTP 429 使用标准 `Retry-After` 秒数或日期；没有有效等待时间时等待 60 秒。其他失败响应若给出有效 `Retry-After` 也遵守。未知业务错误只展示安全提示，不猜测未经核实的 MaaS 错误码，不返回上游原文。

## P07 · 短信登录与可信账号身份

2026-10-03 已接入 `electron/login/session.ts`、受限 `login` IPC 和页面登录动作。主进程请求固定 `smsLogin` 地址，只提交手机号、短信码及已确认的 `origin=app`、`application=uniwork`。图形验证码只用于发短信，不作为短信登录的额外条件。请求不自动重试，窗口关闭会取消请求，迟到响应不能重新建立身份。

主进程一次性校验 UID、token、业务状态和未来有效期，再保存当前窗口的身份。数值 UID 只接受非负安全整数，超大数值拒绝而不四舍五入；字符串 UID 保留规范化后的值。绝对期限按毫秒解析，或按契约的相对秒数计算；过去、缺失、非数值和非法期限均失败，不默认补期限。

UID 和 token 不进入新增 IPC 返回值、日志或磁盘。页面只收到脱敏手机号和有效期，成功后清空并卸载表单；到期重新展示空表单，要求再次登录。有效身份下的重复请求复用当前身份，不重复消费短信码；主进程内不切换到第二个账号。完整退出和切换流程仍属于后续阶段。

人工验收：重启源码开发版，输入手机号和图形码发送短信，再输入收到的短信码点击登录，确认展示正确脱敏账号。当前成功后只展示账号卡片，本地工作空间尚未接入；关闭程序会清除本进程身份，下次启动不能自动恢复。真实 UID 类型、有效期字段、同账号 UID 稳定性仍待真实样本补证。

验证：15 项定向测试通过，覆盖身份与期限校验、请求字段、失败无残留、并发提交、过期重登、关闭取消和页面展示。整组 Electron 检查 5 项通过、1 项真实 MaaS 取图默认跳过；新增登录检查只替换网络响应，实际经过 Renderer、preload、IPC 和主进程，确认失败重试、凭据不进入页面、其他窗口被拒绝和未启动后端，并查看账号卡片截图。开发页首次等待 30 秒超时，单独与整组复测通过；隔离缓存冷启动用时接近上限，测试就绪等待调整为 60 秒，并再次单独检查。完整 TypeScript、相关 ESLint 和差异检查通过。未使用真实手机号或短信码登录。

## P10 · 套餐获取与模型信息解析

- 提交主题：`feat(login): 解析 MaaS 套餐模型并区分查询结果`。
- 行为：解析 `apiKey`、字符串或对象形式的 `models`、`main_model_id`、各模型专用地址。补 `/v1` 的规则沿用核实后的契约，保留专用路径。
- 将有套餐、可信身份下确认无套餐、查询失败分开；没有套餐不取消已经可信建立的账号身份。无 token 的空响应不是确认无套餐。
- 自动检查：多模型、同名不同地址、缺失字段、无 Key、非 JSON、业务失败和超时；不能只按模型名去重后丢掉不同端点。
- 真实验收：页面显示真实账号套餐的模型名称，主进程保管模型 Key；可用的无套餐账号另测。没有样本的情况只报告解析测试结果。
- 边界：不写 Hermes 配置、不调用付费模型。模型 Key 不通过新增 Login IPC 返回页面；原版模型设置能力不在本步改造。

## 阶段出口

- 登录窗口、真实验证码／短信／登录至少完成一次人工链路；加密存储和恢复分别有记录。
- 没有正式恢复验证依据时，准确报告 P09 未完成，不能把阶段标为全部通过。
- 阶段二只接收 Login 主进程产生的可信结果，不能让 Renderer 自行指定 UID 或 Home。
