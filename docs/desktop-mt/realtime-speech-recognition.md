# UniWork 实时语音识别

输入框的麦克风按钮使用 Hexagent UniWork 的元景实时识别协议。点击“开始语音识别”后申请麦克风权限，识别文字持续回填当前草稿；点击停止后等待最多 1.5 秒接收尾句，再释放设备。识别完成后由用户确认发送。

## 入口与账号

- 普通模式显示新的“开始语音识别”入口。
- 原有“语音听写”和语音转文字会话入口仅在开发者模式显示；原有语音设置页沿用开发者模式限制。
- 当前有效登录的元景套餐 Key 只在 Electron 主进程使用。没有有效套餐时按钮会提示重新登录，不读取其他账号的凭据。
- 上游固定为 `wss://maas.ai-yuanjing.com/app/uniwork/asr`，音频使用 16kHz、单声道、小端 PCM16。

## 生命周期

切换会话、隐藏输入框、取消、关闭窗口及渲染进程退出时停止采集和连接。麦克风权限或握手迟到时，结果不能回填其他会话。

录音期间输入框暂停编辑和发送。只允许一个桌面识别连接；单次连接最多 5 分钟，并受账号有效期约束。音频积压过多时结束识别并提示重试。

## 开发与验证

改动同时涉及主进程和 preload，需完整重启 `npm run dev`，仅刷新页面不足以加载新桥接。发行包需要重新构建。

自动验证包括本地真实 WebSocket 的握手、鉴权头、PCM、EOF 尾句、账号撤销及 IPC 来源校验，以及输入框的结果回填、麦克风释放、迟到权限隔离和开发者模式入口。真实设备和元景线上识别仍需在已登录桌面中试录确认。
