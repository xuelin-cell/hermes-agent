# 消息平台界面：阶段一

日期：2026-10-16。范围：仅调整桌面消息平台页面与其配置、扫码界面，沿用 Hermes 现有接口，不修改 Python 后端核心。

## 当前行为

- 按 UniWork 的纵向卡片组织微信 ClawBot、钉钉、飞书、企业微信智能机器人；保留配置指南。
- 5G 消息网关（uniAgentGate RCS）只显示禁用的“待接入”卡片，没有接口或连接能力；不接入 UniBot。
- 钉钉、飞书、企业微信只在弹窗编辑必要的两项凭据，保存时同时启用平台。空输入保留旧值，脱敏占位值不会写回；保存失败保留输入。
- 微信在卡片内取码、轮询、显示已扫码／过期／失败状态；确认后保存，解绑仍需确认。收起只停止页面轮询，不新增后端取消接口。
- 卡片区分未连接、已停用、网关停止、连接中及接口报告的连接状态，不因凭据已保存就显示已连接。
- 隐藏其它平台、Profile 选择、白名单、群聊规则及高级字段，不清除或覆盖已有配置。解绑只停用选中平台并移除其必要凭据，保留历史、文件及其它配置。
- 请求仍携带原有配置 Profile 作用域；作用域改变会关闭旧弹窗并停止旧扫码轮询。没有更改消息与桌面的会话组织。

## 网关边界

普通凭据保存继续使用原生接口：接口报告热生效时刷新状态，否则显示手动重启提示。微信继续复用既有扫码插件的自动重启与桌面失败恢复入口，不重复发起重启。

本轮不实现应用启动后自动恢复网关、保存前在线验证凭据、按平台热更新或重启性能优化。现有连接及鉴权规则未改；卡片状态的准确程度仍取决于原生接口，不代表新增了上游在线探测。

## 验证与限制

- 消息页与语言目录定向测试：36 项通过。覆盖四个平台的原生请求、必要字段、保存失败、解绑确认、作用域切换、迟到取码／确认结果，以及网关停止时不显示已连接。
- 完整 TypeScript、修改文件的 ESLint、截图脚本语法与 Git 差异检查通过。
- 独立隐藏 Electron：真实加载展示组件、主题、二维码库与弹窗，在浅色／深色、900／460 像素四种组合检查卡片、凭据保存、等待扫码及已扫码；另检查过期和已连接展示。无横向溢出和页面运行错误。
- 上述接口响应为受控数据，不连接真实消息平台，不发送短信或调用模型。真实微信扫码、钉钉／飞书／企业微信连接和消息收发仍需人工回归，不能把界面检查视为真实平台已经验收。
