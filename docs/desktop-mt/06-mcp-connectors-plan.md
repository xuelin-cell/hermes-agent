状态：M01 完成，M02 页面组织已实现；M03 收敛为复用原生管理，定向模拟验证已完成，实际桌面仍待人工核验。M04～M06 未开始。原生验证基线为同步远端后的 `12a5faa603`。本文不授权后续推送。

## 1. 目标与已确认的范围

界面参考 UniWork，MCP 配置、连接、工具发现和调用复用 Hermes 原生能力。先做能够端到端使用的通用 MCP 管理和 Playwright，不复制 UniWork 的运行时生效机制。

- 当前只面向 Windows 桌面本地多账号、源码开发运行。
- MaaS 账号之间隔离；同一账号内部按 Hermes Profile 管理 MCP，不自动跨 Profile 同步。
- 页面采用内置／自定义分组、列表与展开编辑，沿用 Hermes 组件、主题和国际化。
- 支持自定义 MCP 新增、编辑、删除、启用、禁用和连接测试。
- 保留原生 JSON 编辑、OAuth、工具详情和工具过滤能力。
- 首批内置项只做 Playwright，包含安装、配置接入和真实浏览器操作验证。
- 用户明确要求：实施中存在问题应及时讨论，不自行扩大范围或用临时回退掩盖问题。

本轮不做推荐连接器、OpenConnector、arXiv、小红书、uniai-toolkit、技能市场迁移、文档预览、云端接入或独立安装包。它们是独立待办，不代表取消。

## 2. 原生行为与复用原则

以下是基线源码事实，尚未作为本轮运行验收结果。

| 操作 | 当前原生行为 | 本轮处理 |
| --- | --- | --- |
| 新增 | 明确保存配置，再异步重载并探测连接；普通新增配置默认启用 | 复用，不改成默认禁用或测试通过才保存 |
| 编辑 | 保存后写入配置并重载 | 保留保存／取消，不做输入过程自动保存 |
| 启用 | 保存启用标志，触发重载和连接测试 | 测试失败不自动改回禁用，准确显示失败 |
| 禁用 | 保存禁用标志，再重载 | 不等同于关闭远程 MCP 服务器 |
| 删除 | 删除配置记录，再重载 | 不卸载软件、不删除用户文件 |
| 工具过滤 | 保存工具过滤配置，再重载 | 使用已有工具过滤能力 |
| 重载 | 重建 MCP 连接、发现工具并刷新已创建的会话 Agent | 正常成功后不要求新建聊天或重启桌面 |

关键边界：

- 保存成功不等于重载完成，更不等于 MCP 工具调用成功。
- 当前桌面异步触发 `reload.mcp`，没有统一等待全部聊天空闲的门槛。重载可能影响正在执行的 MCP 调用及同一后端进程的其他会话，也可能使提示词缓存失效。
- 本轮不额外实现空闲延迟、Agent 缓存管理或新的重载策略，不承诺无感切换。
- stdio MCP 子进程由原生 MCP 生命周期管理；远程 HTTP 服务只建立或断开客户端连接。
- 后端运行期间通过原生 MCP API 修改配置，不由 Electron 或 Renderer 并发直写 `config.yaml`。
- 不扩大凭据暴露面；复用现有凭据机制，不额外复制到页面存储、日志或第二份配置。

主要源码入口：

- `apps/desktop/src/app/capabilities/mcp/use-mcp-servers.ts`：保存、启禁用、删除、探测与重载调用。
- `apps/desktop/src/app/capabilities/connectors/`：现有连接器页面、表单、详情与工具视图。
- `apps/desktop/src/api/mcp.ts`：现有 MCP API。
- `hermes_cli/web_routers/mcp.py`：原生配置与连接测试接口，仅阅读复用。
- `tui_gateway/methods_tools.py`：原生重载与会话工具刷新，仅阅读复用。

## 3. 修改位置与上游边界

不修改 Hermes Python 后端核心、原生 MCP Python 路由或运行机制。本轮不新增 Python 管理接口或插件路由；通用 MCP 管理已有原生 API，无须另建一套。

| 职责 | 位置与约束 |
| --- | --- |
| MCP 页面展示 | 新增独立桌面组件，复用原生控制器；现有页面只做必要接线 |
| 配置、认证、探测、工具过滤、重载 | 调用既有 Hermes 能力，不复制实现 |
| Playwright 依赖安装与本机资源定位 | Electron 主进程独立模块，先评估既有安装能力 |
| 安装入口 | 受限 IPC 与类型化 preload；不向 Renderer 提供任意命令执行能力 |
| 日常 MCP 与浏览器运行 | 原生 MCP 管理；不再加一套 Electron MCP 守护器 |
| 文案、测试、使用说明 | 跟随对应小步骤更新 |

优先新增文件，但不能承诺零修改上游已有文件。页面挂载、主进程注册、preload、类型及翻译可能需要少量接线；每步开始前列出具体文件和必要性。不要为减少表面改动量复制原生控制器或建立通用扩展框架。

工作：

1. 重新检查 Git 状态、当前代码和适用规范，保留已有未提交内容。
2. 使用独立测试 Home 和最小 MCP 服务，验证新增、保存、启禁用、删除、工具发现和真实调用。

4. 研究 Playwright MCP 官方文档、依赖和参数，评估现有 Node、包管理与浏览器资源；不得假定 `agent-browser` 的浏览器版本可直接复用。
5. 确定固定依赖版本、来源、启动参数、安装和浏览器数据目录、安装后启用方式。实施前把这些决定补入本文。

验收：已有配置完整显示；浅色、深色和窄窗可用；原生插件提供的 MCP 或工具入口不被丢弃或误判为可删除的自定义配置。不新建持久化 MCP 数据副本。

验收：

- 定向模拟新增、JSON 保存、启禁用、测试失败和删除，检查不误改其他服务或 Profile；实际重开与服务调用留作人工验收。

### M04：Playwright 安装与配置接入

工作：

- 用户明确点击安装后才下载，不在登录或打开页面时自动安装。
- 主进程使用 M01 确定的固定依赖、安装能力和目录；IPC 绑定可信窗口与当前账号，不接受任意命令或任意安装路径。
- 安装完成后，通过原生 MCP API 接入选定 Profile，再按原生流程重载和测试。
- 同名自定义记录或已有资源冲突时保留原状并提示，不按名称猜测所有权、不覆盖。
- 失败提供明确原因与手动重试，不无限重试、不写虚假成功状态。

资源约束：安装资源位于当前账号受管目录，浏览器状态与输出按账号／Profile 隔离；不连接用户日常浏览器，不复用官方版浏览器用户目录。不新增卸载或清空用户浏览器数据功能。

验收：从未安装到发现工具走通；失败、重复点击、账号切换和迟到安装结果不污染其他账号或 Profile。安装完成不等于功能验收完成。

### M05：真实浏览器操作与生命周期

工作：通过 Hermes 使用的真实 MCP 链路，对独立测试页面执行导航、读取、点击、输入和截图；验证禁用、再启用、应用重开以及账号退出／完整退出后的收尾。

验收：

- 不以仅连接成功或列出工具代替实际执行。
- 受管服务和浏览器进程可以安全收尾，不误停其他账号或用户浏览器。
- 不使用个人浏览器状态，不操作用户正在使用的窗口。
- 发现残留先调查归属和原生行为；需要修改 Python 核心时暂停讨论，不批量按进程名结束程序。

自动化直接验证真实工具调用，不需要付费模型。真实模型选择并调用工具另由用户人工验收，不将二者混为同一证据。
