# 免费搜索可靠性

本地搜索继续使用现有 Exa、Parallel、Firecrawl、Keenable 匿名服务，不接入元景搜索。

## 有限切换

- 匿名访问明确被拒绝、429 限流、连接失败、读取超时及临时服务端故障可以换下一家；每家每次最多尝试一次。
- 参数错误、未知 403、网站访问策略拒绝和证书校验失败不继续换源。用户取消后不再发起下一次请求。
- 备用服务成功即返回正常结果；内部失败分类不会进入桌面协议。全部失败仍明确返回失败摘要。
- 单次网络等待收紧到最多 8 秒，整次搜索采用 30 秒尝试预算，预算耗尽后不再启动下一家。
- 该预算约束后续尝试及网络等待，不是终止操作系统 DNS／网络调用的硬实时期限；HTTP 客户端的读取超时也不是整份响应的总时限。
- 保持免费／付费选择及禁用规则，付费请求和网页抓取流程不随此修复改变。

## 短期避让

- 明确的匿名访问拒绝暂避 5 分钟；网络及临时服务故障暂避 30 秒。
- 429 优先采用服务返回的 `Retry-After` 秒数或 HTTP 日期，无效时暂避 1 分钟。
- 状态仅保存在当前进程内，并按账号／Profile 的 Home 与服务分开。退出应用后清空，不写入配置或数据库。
- 暂避期间继续使用其他可用服务；期限结束后仅放行一个恢复探测，成功后恢复正常使用。
- 并发的迟到成功不会覆盖新登记的故障；网络调用不在状态锁内执行。
- 所有服务都失败或暂避时仍返回失败摘要，不伪装成成功或空结果。

## 验证

独立 PM 测试环境通过 `scripts/run_tests.sh` 执行以下定向文件，两步完成后共 83 项通过：

- `tests/plugins/web/test_keyless_search_reliability.py`
- `tests/tools/test_web_keyless_fallback.py`
- `tests/tools/test_web_keyless_rescue.py`

覆盖匿名拒绝、网络故障、取消、预算、限流恢复、并发探测及 A→B→A 暂避隔离。回环 HTTP 检查实际执行正式 Firecrawl／Keenable 适配器的请求和解析，确认 403 后备用成功，后续请求跳过暂避服务；该服务响应受控。

当前网络下另用独立 Home 进行两次真实匿名搜索，两次均由 Keenable 返回结果，Firecrawl 登记为暂避。没有使用元景、模型或付费接口。
