# 聊天区工作目录选择

日期：2026-10-14。状态：已实现，定向检查通过；真实账号使用待人工验收。

## 行为

参考 UniWork 的“选择工作目录”，放在聊天输入框“+”按钮右侧。

| 场景 | 行为 |
| --- | --- |
| 新对话 | 按钮默认显示“默认工作区”（账号的 `workspace` 目录）。下拉菜单可选默认工作区、最近使用的目录（最多 8 个），或通过系统窗口选择其他文件夹。选默认工作区时，每个新对话在其中自动建一个 `YYYYMMDD-HHmmss` 文件夹（2026-10-19 起，见[每个对话独立工作文件夹](13-conversation-folders-plan.md)），这些文件夹不列入“最近使用” |
| 对话开始后 | 只显示目录名（自动建的文件夹显示时间名），点开是完整路径和只读说明：“本次对话已绑定该目录……如需使用其他目录，请新建对话” |
| 禁止的目录 | 与 UniWork 相同：盘符根目录、`C:\Windows`、`C:\Program Files`、`C:\ProgramData`、`C:\Users` 和用户主目录本身；只拦这些目录本身，子目录允许 |
| Bot 对话、新手引导对话 | 不显示 |

与 UniWork 的差别：

- 不做“允许／始终允许”弹窗。Hermes 不把 agent 限制在所选目录内，目录只决定终端从哪里启动、相对路径从哪里算；菜单底部只提示“Agent 会在这个目录中读写文件”。
- 最近目录取自已有会话的目录，不另存一份列表。
- 选了不属于任何项目的目录时，侧边栏按 Hermes 原有规则自动以该文件夹建立分组（`tui_gateway/project_tree.py::_auto_buckets`）。

## 实现与复用

| 部分 | 位置 |
| --- | --- |
| 选择器、目录规则、文案、测试 | 新增 `apps/desktop/src/app/chat/composer/workdir-mt/` |
| 挂载 | `apps/desktop/src/app/chat/composer/index.tsx` 增加一个导入和一行渲染，是唯一改动的上游文件 |
| 截图夹具 | 新增 `apps/desktop/scripts/workdir-picker.renderer.mjs` |

- 新对话选目录复用原生 `useCwdActions().changeSessionCwd`（此前没有界面调用它）：写入新对话目录并标记为用户主动选择（`cwd_explicit`），发送时由原生 `session.create` 带给后端。
- 回到默认工作区与新建对话时“未选目录”的状态相同；本机账号环境下发送时改用自动建的对话文件夹，其它环境后端仍使用 `TERMINAL_CWD`。
- 系统选择窗口用原生 `selectDesktopPaths`；默认工作区路径由原生 `config.get project` 读取。
- 文案用 Hermes 的作用域文案包（`registerPluginLocales`）随模块自带，不改上游语言文件；提供简体、繁体和英文，其他语言回退英文。
- 不改 Python。选择器本身不改 Electron 和 preload；对话文件夹由主进程建，另加了两个受限接口（见第 13 篇）。

为什么改输入框文件：输入框虽然有扩展插槽，但只有内置插件能自动注册进去，而插件只能使用插件 SDK；SDK 没有设置新对话目录和选择文件夹的能力，补进 SDK 要改更多上游代码。直接在输入框挂一行改动最小。

## 验证

- 新增单元测试 12 项通过：禁止目录、最近目录排序与去重、新对话目录的判断规则、选择目录、回到默认、拒绝主目录、对话开始后迟到的选择被忽略、只读显示。
- 去掉“对话开始后不再改目录”的保护后，对应测试会失败，确认测试有效。
- 输入框原有测试 77 个文件、551 项全部通过；TypeScript 与相关 ESLint 零警告。
- `node scripts/workdir-picker.renderer.mjs`：隐藏 Electron 窗口加载真实组件、主题和样式，浅色／深色、900／460 像素四组的收起与展开状态，以及锁定状态截图检查通过，无横向溢出和运行错误。夹具按输入框的网格排版，不是完整输入框。
