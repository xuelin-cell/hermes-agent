# 退出、到期、故障恢复与验收状态

适用范围：Windows 源码开发版。实现位于 `electron/entry_local/`、`electron/login/` 和原版桌面生命周期接线。

## P18 · 账号角标

右下角显示脱敏手机号和退出按钮。主窗与完整副窗通过只读 IPC 获取本次已准备账号；接口校验窗口、主框架、账号 Session、桌面来源和参数，不返回 UID、token、Key 或路径。

展示字段不变时保持对象引用，聚焦及定时刷新不关闭已打开的退出确认。运行中到期仍保留账号和退出入口。

## P19 · 退出账号

确认后持久保存 `logout` 意图，撤销内存身份并封闭后端、终端和窗口入口。取得可信进程快照后，销毁旧账号页面与 PTY，显示官方 `ConnectingScreen` 样式的“正在退出账号…”等待画面。

等待窗沿用当前窗口尺寸、背景和明暗模式，使用独立非持久分区，不加载 preload，拒绝导航、弹窗和权限请求。

停止及最终验证成功后释放后端归属，删除 `maas-login.enc` 和运行／退出记录，再受控重启 Electron 到登录页。账号 Home、工作区、浏览器分区及配置保留。

## P20 · 账号消息网关

`gateway-logout.py` 是桌面退出适配程序，复用原版网关身份、PID、计划停止标记和带创建时间防护的终止函数。

只检查当前账号 Home 和可验证的直接 Profiles；运行环境固定 `HERMES_GATEWAY_LOCK_DIR=<账号 Home>/gateway-locks`。原版生成的账号计划任务禁用，Startup 文件移入账号内备份；登录不会自动重新启用它们。无法确认的外部监督器阻止退出成功。

一次正常退出复用一个短生命周期 Python 适配进程及其中的 PowerShell 查询进程。归属快照、停止前复核、最终检查分别读取新鲜进程状态；首次进程表同时供普通子树与网关归属使用。返回 Electron 的仅为归属字段，不含命令行或凭据；失败和收尾释放辅助进程，重试重新创建。

## P21 · 托管工作与完整退出

停止先处理消息网关和自动拉起来源，再释放终端、等待在途启动结束，并行等待原版本地后端、主连接和后端池收尾。随后只补清理仍存活的可信 PID 子树，核对创建时间并最终检查网关。PID 复用不能作用于无关新进程；全部已结束时不启动额外 PowerShell。

桌面 PTY 和后端子树在页面销毁前取得快照。后台命令、Cron 脚本、MCP 子进程沿用原版生命周期；任务定义和工具配置不删除。定时补跑沿用原版规则，不新增桌面补跑策略。

| 操作 | 界面与最终行为 |
| --- | --- |
| 退出账号 | 快照后显示等待画面；停止成功后清登录并重开登录页 |
| 完整退出应用 | 确认后立即隐藏窗口、移除托盘，后台停止；保留登录，不重开 |
| 关闭到可用托盘 | 隐藏窗口，后台工作继续 |
| 取消退出确认 | 保持当前账号工作，不写退出意图 |

完整退出先隐藏窗口，快照成功后才销毁。退出期间托盘、第二实例和迟到窗口不能恢复旧账号页面；原托盘偏好不改写。窗口消失不等于后台进程已经停止。

## P22 · 运行中到期与鉴权拒绝

按原登录期限在右下角提示“登录已到期”，非阻塞通知在当前账号组件中只提示一次；聚焦与定时检查不续期、不自动注销、不锁界面、不停止任务或重启。

套餐 HTTP 401／403 记录为 `planAuthRejected`，不取消身份；其它网络、限流、服务和解析失败不推断为登录到期。模型错误仅在出错提供方为本产品管理的 MaaS 提供方且错误层为 `auth` 时补充重新登录建议。

登录 token 与模型 Key 是不同凭据。后续模型调用能否成功由平台授权决定，客户端期限提示不保证它们同时失效。

## P23 · 启动失败

目录、配置、账号凭据、运行组件或后端失败显示固定安全说明；空间不足和权限问题给出对应建议，不回显原始异常、路径或凭据。

提示仅提供“退出应用”，复用完整退出；修复后重新打开再准备原账号。不在半初始化主进程中重复启动，不自动重置配置、安装依赖或切换运行环境。历史和登录记录保留。

## P24 · 停止失败

归属无法确认、超时、停止无效、子进程残留或网关重新拉起时，不清除停止记录和归属，不放行另一账号。

失败才显示等待窗和“重试／关闭应用”提示。只有显式重试再次停止；关闭应用以失败结束，保留证据。并发请求合并，首次退出意图保持不变，应用退出的重试不变成注销。

## P25 · 崩溃恢复与遗留清理

开始账号工作前，`recordAccountRun()` 在应用 `userData/maas-logout-pending.json` 写入账号摘要和默认 `quit` 意图；正常运行时该文件也存在。用户确认退出账号后改为 `logout`，完整停止后删除。

重开先取得单实例锁，再按持久记录定位原账号，不依赖登录仍有效。复核后端、父实例、创建时间、可信子树与账号网关，保存归属后停止并最终检查。每次启动只清理一次，失败保留原件并阻止登录，不无限自动重试。

成功后按原意图处理凭据：`quit` 保留原登录及期限，`logout` 清除登录。随后才恢复未到期身份或显示登录页。坏记录、目录链接、未知指纹或仍活着的原父实例不能绕过门禁；复用 PID 的无关实例跳过。

恢复只处理已有持久归属、仍可追溯的子树和账号网关，不保障找回没有归属证据且已脱离父进程的任意程序。

## P26 · 当前验收状态

当前为部分验收完成。已有隔离夹具实际经过 Electron、preload／IPC、Windows 系统加密、文件读写、原版 Python 后端、REST／WebSocket 和进程停止。

| 项目 | 现有证据 |
| --- | --- |
| 登录与恢复 | 受控 MaaS 响应链、真实系统加密及跨进程恢复；真实验证码取图与刷新 |
| A→B→A | 受控身份下的账号文件、连接、草稿、Cookie、localStorage、IndexedDB 和预览分区复用 |
| 退出与托盘 | 原版后端、后台命令、脚本 Cron、受控 stdio MCP、PTY 和网关的真实进程检查 |
| 运行中到期 | 短期限夹具中任务继续、手动退出有效，冷启动拒绝到期记录 |
| 故障与恢复 | 隔离启动故障、停止故障、失败重试、崩溃及重开清理 |
| 退出展示 | 真实 Electron 的浅／深色等待页、完整退出隐藏与失败页面 |

已知问题：套餐返回 HTTP 401 时，主进程拒绝标志保留，但首次进入聊天页的重登提示未通过可见性验收。

尚未完整验收：真实短信双账号、跨登录 UID 稳定性、真实套餐／有效无套餐模型调用、实际对话正文、真实第三方 MCP／消息平台、官方版并行、系统重启与休眠唤醒、安装包。受控响应和脚本任务结果不替代这些人工或平台验收。
