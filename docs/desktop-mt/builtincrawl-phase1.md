# BuiltinCrawl 第一批正确性与候选保留

日期：2026-11-03。基于 release `140c408b87822ac2a7822b2e8b6f9cda6906ce35`，独立 `webcrawl` worktree 已先恢复到该创建基线，再复核并重新应用第一批改动；当前 HEAD 仍为该基线，全部改动未暂存、未提交，未合并或部署到 release。

当前已补充共享可读证据与按需逐级抓取：HTTP先行，明确缺口才渲染，渲染后足够则停止，仍缺内容才等待/展开/滚动。Builtin缓存为v12；隐藏、未知及计算样式证据贯通提取、评分、采样与缓存；已继续修正可读区域、原生隐藏、jQuery滚动与异步薄壳提前停止。最新范围和验证见 [交互加载说明](builtincrawl-interactive-loading.md)。此前20文件509项属于修复前A1验证，下文保留第一批的实现与历史验证边界。

## 实际行为

- 正文及发现链接统一读取首个 `base[href]`，非法基准回到最终页面地址。普通章节锚点去重；明确 `#/`、`#!/` 路由保留。浏览器在地址检查后只恢复导航片段，最终链接使用实际页面地址。静态首页不能冒充目标路由正文。
- HTTP 与浏览器候选都评估可用性。保护短公告、表格、列表及正文中对登录/验证的正常讨论；错误/登录/验证页不能因文字多而成功。标题仅为线索，联合正文结构、主登录表单与挑战组件判断；普通候选按可用性、结构、长度排序，经过独立评估的真实交互新增内容优先保留，薄弱占位不享有此优先级。保持原正文提取器与推荐区处理。
- 是否需要补抓和正文能否使用分别判断。已有短正文不会仅因字数少被否定；检测到动态加载迹象仍补抓。第一批本身没有新增交互；当前有限滚动/阅读点击见交互加载说明，仍无持久会话。
- Builtin 总预算传到排队后的 worker，浏览器有局部时限并留出结果返回和清理时间。普通渲染失败/局部超时保留合格静态正文；用户取消、安全拒绝和错误路由内容不能伪成功。浏览器主页面被网络策略拒绝时保持安全失败。
- `fetch_status=usable|partial|unavailable`、`engine=http|chromium` 与有限原因码贯通 worker、缓存和原生工具整理。原生截断仍有原提示，二进制拒绝改为 unavailable。仅 usable 入版本化 Builtin 缓存；partial/失败和旧未评估缓存不被当作普通成功复用。

## 代码边界

修改限于 `apps/desktop/assets/unisearch-plugin/`、定向插件测试及本文。
新增 `fetch/builtin/urls.py`、`quality.py` 和轻量 `fetch/status.py`；状态模块不导入第三方解析器，不破坏惰性发现。
`fetch/providers.py` 与 `tool_adapter.py` 是共享文件，但新逻辑限于 `builtin_parse` 分支；UniCrawl 请求体、凭证、重试、缓存和原生其他Provider分派保持。
Hermes Python 核心、工具schema、共享 `FetchResult`、插件依赖声明、全局缓存/救援开关及真实账号配置未修改。

## 实际验证

通过 PM 在临时目录建立独立开发测试环境，未向用户账号安装依赖。执行：

```sh
env HERMES_PYTHON=/private/tmp/webcrawl-r219-fullenv/bin/python HERMES_TEST_FILE_RETRIES=0 bash scripts/run_tests.sh tests/plugins/test_unisearch*.py -q
```

本次重新执行：原始基线的 6 个链接回归用例全部失败（基准地址及应用路由）；重新应用修复后，13 个文件，187 项通过，0 失败。新增正文/链接/缓存契约24项，加一项贯通多个场景的真实浏览器/worker测试和一项输出边界测试；既有替身只补新 Builtin 返回协议，原来的行为断言保留。

真实集成使用 macOS 上独立的无窗口 Chromium、本机HTTP夹具和临时 Profile A→B→A：实际启动子进程，运行生产导入/取页/解析/渲染/缓存/工具整理及原生SQLite消息写入。仅测试网络边界映射到受控localhost，浏览器路径指向现有测试资源，不绕过真实产品配置写入用户账号。
覆盖两个hash页面返回不同正文、partial重试、验证页拒绝、主页面跳转被禁止、5秒共享预算下真实浏览器导航挂起仍返回HTTP正文、全部9个worker退出，以及工具结果质量字段经过原生不可信数据包装和历史落盘后保留。A回切命中A的自身缓存，B独立取页；子进程不继承套餐凭证。

完整插件回归覆盖原提取器的表格/列表/分页/评分/推荐区行为、其他Provider原生参数、UniCrawl协议/凭证/重试、独立缓存、网站策略、取消回收与历史桥接。另检查变更白名单、差异空白和定向 Ruff。

## 验收边界与后续

以上是隔离机制和实际引擎集成验证，不是用户账号完整 Electron/模型对话验收，也不是公网网站成功率测试。Windows/Linux 上的浏览器启动、进程间预算与清理尚待原平台验证；macOS通过不代填跨平台验收。

质量判定仍是可解释启发式；`usable` 不承诺全文完整。未知hash形式仍按普通锚点处理。动态页面缺少明确加载提示时仍可能遗漏内容；第一批本身不含主动交互；当前有限滚动/展开已补充，翻页仍交回已有浏览器工具。
外层整批超时、用户取消、worker崩溃/强杀不保证抢救内存候选；整批已完成URL保留仍待独立修复。Builtin域名规则缓存前重验、连接IP固定和浏览器全部出站闭环仍未完成，不能据本次局部拒绝用例宣称全部SSRF问题已解决。

合并后需重新构建随桌面发行的插件资产并重启相应后端，才能在产品中使用；本次没有操作用户正在使用的桌面窗口、改其Profile或自动推送。
