# 办公场景与提示词模板

新对话的输入框上方显示 UniWork 办公目录。普通模式和开发者模式均可使用；已有聊天记录的会话、Bot 对话、引导流程及紧凑浮窗不显示。

## 完整交互

- 一级标签遍历云端 `modules`，数量、名称、排序来自配置；下方显示所选模块的 `tags`，再点击分类进入 `templates`。不使用内置 JSON 默认目录。
- 点击分类进入该分类的模板列表，并显示可取消的分类标签。与 Hexagent 原有交互一致，选择分类会清空当前输入文字。
- 点击模板后将完整提示词替换到草稿，聚焦输入框末尾。模板选择有高亮，可悬停查看完整提示词；不会自动发送。
- 取消分类返回首层列表，保留已填草稿。切换会话或语言时清除分类选择。
- 列表支持横向滚动、滚轮及左右分页按钮。只有相应方向存在隐藏内容时显示箭头；列表边界不会拦截页面滚动。
- 录音、生成回复或输入框不可用时不能通过模板覆盖草稿。

## 数据来源与缓存

固定配置接口为：

`https://maas.ai-yuanjing.com/app/gateway/uniwork/system-config?key=welcome_config_v3_<locale>`

语言只允许 `zh-CN` 和 `en`。响应外层 `configValue` 为包含 `modules` 的 JSON 字符串。

主进程用当前登录身份读取远端配置，校验后只向可信桌面主框架返回目录。页面无法指定任意地址或提供凭据。不读取任何层级的 `enabled`；分类和模板的重复 ID、无效条目会被过滤，并按 `sort` 稳定排序。分类和模板只来自所选模块。

有效目录持久保存在 Renderer 的 `uniwork.welcome.modules.v3.<locale>` 键中。启动先显示上次获取的云端缓存，再更新远端；无缓存时等待云端，失败提供刷新入口。空模块、网络或解析失败保留原目录。同语言请求合并，五分钟内复用最近的读取结果。更新目录不会自动改写已编辑的草稿。

模块、分类和模板均支持 `"icon": "presentation"` 这样的 Lucide 图标名称。客户端从已安装的 `lucide-react` 图标库按名称加载，不再按标签 ID、名称、工作区选择图标。没有 `icon`、名称不支持或图标加载失败时只显示文字。

模块的 `workspace: "codex"` 切换代码工作区，`"work"` 使用办公/学习工作区，显式字段优先。兼容尚未提供该字段的旧版云端配置：“代码开发”“编程”及原有英文代码模块名称仍进入代码工作区，其余进入办公/学习工作区。模块位置键与云端分类、模板 ID 仅供选中状态和 React 渲染使用，不作为本地业务映射。

该功能同时涉及主进程与 preload，开发时需要完整重启 `npm run dev`。发行版需要重新构建安装包。
