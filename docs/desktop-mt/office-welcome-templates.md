# 办公场景与提示词模板

新对话的输入框上方显示 UniWork 办公目录。普通模式和开发者模式均可使用；已有聊天记录的会话、Bot 对话、引导流程及紧凑浮窗不显示。

## 完整交互

- 首层显示分类。当前内置目录包含文档处理、幻灯片、帮我写作、数据分析、会议纪要、深度研究、视频搜索、金融理财、生活娱乐，共 9 类、34 个模板。
- 点击分类进入该分类的模板列表，并显示可取消的分类标签。与 Hexagent 原有交互一致，选择分类会清空当前输入文字。
- 点击模板后将完整提示词替换到草稿，聚焦输入框末尾。模板选择有高亮，可悬停查看完整提示词；不会自动发送。
- 取消分类返回首层列表，保留已填草稿。切换会话或语言时清除分类选择。
- 列表支持横向滚动、滚轮及左右分页按钮。只有相应方向存在隐藏内容时显示箭头；列表边界不会拦截页面滚动。
- 录音、生成回复或输入框不可用时不能通过模板覆盖草稿。

## 数据来源与缓存

迁移自 Hexagent UniWork 的办公模块 `office`。固定配置接口为：

`https://maas.ai-yuanjing.com/app/gateway/uniclaw/system-config?key=welcome_config_codex_<locale>`

语言只允许 `zh-CN` 和 `en`。内置 JSON 是 2026-10-15 从上述公开系统配置读取的办公模块快照，仅保存分类、模板及其显示配置，不包含接口返回的维护人等元数据。

主进程用当前登录身份读取远端配置，校验后只向可信桌面主框架返回目录。页面无法指定任意地址或提供凭据。停用项、重复项和无效模板会被过滤，并保持服务端排序；不会以编程模块代替缺失的办公模块。

有效目录持久保存在 Renderer 的 `uniwork.welcome.office.v1.<locale>` 键中。启动先显示缓存或内置目录，再更新远端；网络或配置解析失败时保留原目录并提供刷新按钮。同语言请求合并，五分钟内复用最近的读取结果。更新目录不会自动改写已编辑的草稿。

该功能同时涉及主进程与 preload，开发时需要完整重启 `npm run dev`。发行版需要重新构建安装包。
