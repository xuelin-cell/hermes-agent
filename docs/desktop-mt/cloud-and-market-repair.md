# 技能市场、个人云盘与本地产物

更新：2026-10-13。代码核对基线：`aebebfc9ef`。本页说明已接通的代码与证据边界，不代表真实双账号或全部技能已经验收。

## 技能市场与内置包

推荐和市场使用固定 UniWork 公共目录，本机 Hermes 注册分类、列表和安装路由。目录请求不发送 MaaS 登录凭据，公共目录相同不表示账号共享已安装文件。安装使用当前账号及 Profile 的技能目录，沿用 Hermes 隔离、扫描与安装登记；完成后刷新列表，新会话加载，不改变已有会话提示缓存。

市场 UI 当前只加载首批 100 条，分类与搜索针对已加载列表。已安装管理可展示当前平台或依赖尚未就绪的包，因此“看得到／已安装”不能证明能运行。

发行标记 `skills/UNIWORK_BUNDLED_ONLY` 使默认集合收敛到 18 个 UniWork 技能；内部必需的 `hermes-agent` 保留但不在用户列表展示。更新同步时，仍被随包 manifest 跟踪的旧副本按规则处理：未修改的移除，修改过的移入 `skills/.retired-hermes`；主动市场安装与自建内容保留。不应笼统描述成删除用户全部旧技能，也不应将缺依赖误判为安装丢文件。

2026-10-13 检查的账号中，18 个包共 351 个资源文件与当前仓库一致，运行缓存不计入比对。市场安装登记为空，说明这批来自内置同步，不是运行环境自动安装记录。当前部分技能仍缺运行依赖、存在旧宿主路径或需要独立业务授权，不应把文件完整与运行就绪混为一谈。

## 个人云盘

云盘复用 Electron 主进程的当前 Login 身份，不使用已删除的 Python 登录代理或 Renderer Web 缓存。受限账号 IPC 校验窗口、主框架、当前账号 Session 和页面来源；固定请求地址与操作范围，不将 UID、完整手机号或 token 返回页面。

新登录将云盘认证需要的完整手机号保存在原系统加密记录。旧记录只有脱敏手机号仍能恢复本地桌面，首次使用云盘需退出重登一次；历史、工作区与任务定义不删除。

现有 UI 支持目录分页、返回上层、当前目录搜索、新建文件夹、重命名、移入回收站和获取预览／下载链接。没有上传入口、移动 UI 或容量展示。明确的云盘 token 过期只刷新并重试一次，普通网络和服务失败不自动退出账号；身份到期拒绝云盘请求，不改变本地任务的既有到期规则。

预览由签名链接交给现有预览浏览器，下载由系统浏览器处理，不自动保存到账号工作区。Office 在线渲染取决于上游和浏览器。系统浏览器的登录状态及下载位置不属于 Hermes 的账号浏览器分区。

### 云盘授权证据边界

当前 token 兑换固定请求 `https://www.yjworker.10010.com/app/gateway/uniwork-yunpan/access-token`，提交手机号和 appVersion，没有附带 MaaS token。后续固定云盘业务请求同时携带 MaaS Bearer token 和 `X-Drive-Access-Token`。

客户端已绑定当前身份，不意味着上游已经验证 UID、手机号和云盘所有者的关系。需要确认服务端契约，使用真实 A→B→A 验收文件归属、登录恢复与过期处理；这是未验证的授权边界，不是已证实串号或漏洞。受控网络测试不能替代真实服务验收。

## 与本地产物的区别

| 范围 | 当前含义 |
| --- | --- |
| 个人云盘 | 远端服务已有的文件和文件夹；不是云端 Hermes，也不是平台 PostgreSQL |
| 本地产物 | 从近期会话消息整理图片、文件和链接的索引，不是独立存储空间或电脑全部文件浏览器 |
| 本地实际文件 | 通常存放在会话工作区或用户选定项目；链接条目也可能指向外部内容 |
| 会话、记忆和配置 | 保存在账号 Hermes Home，不自动上传到云盘 |

界面能看到云文件不代表 Agent 已经读到它；用户需要明确下载或交给任务处理。本地产物不自动上传，云盘也不自动同步工作区、会话或记忆。

## 验收与发布边界

本地登录和聊天不以云盘或公共目录服务成功为前提。真实账号的云盘隔离、业务操作及技能调用仍待验收。

纯浏览器没有桌面主进程身份桥，不能直接照搬这套凭据链；Web 属于 `feat/hermes-ch`。源码更新不会自动更新旧安装包，独立分发仍需运行时、产品身份及更新渠道适配。
