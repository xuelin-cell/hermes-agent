# 技能市场与个人云盘恢复

当前能力页面的推荐和技能市场使用固定 UniWork 公共目录，后端注册分类、列表和安装路由。安装沿用 Hermes 标准扫描与隔离链，新增技能不改变已有会话提示缓存。

个人云盘不再使用已删除的 Python 登录代理或 Renderer 的 Web 登录缓存。桌面主进程保管当前登录 token 和加密保存的完整手机号，通过固定地址换取云盘 token；接口按路径及方法限制，其他账号分区和子框架不能调用。

此前登录记录仅保存脱敏手机号。旧账号首次使用云盘，需要退出账号并重新登录一次；不丢弃会话、工作区文件或任务定义，不将手机号和 token 返回页面。

云盘支持目录分页、返回上层、当前目录搜索、新建文件夹、重命名和移入回收站。明确的云盘 token 过期只刷新并重试一次，网络或上游失败不会自动退出账号。文件通过签名链接交给现有预览浏览器或系统浏览器；Office 文件不保证在线渲染，取决于上游链接响应和浏览器能力。

本次恢复针对 Electron 桌面及其共享 Renderer。纯浏览器部署没有桌面主进程的身份桥，需要单独提供服务端登录与云盘代理，不能把桌面凭据交给浏览器。

源码修改不会更新已经安装的旧桌面包。开发调试需完整退出再运行；分发时需重新构建并安装新包。
