# 消息平台图标

侧栏消息平台分组使用的官方标志（Simple Icons 已下架这几家的标志）。都是透明底的标志本身，和微信图标一样叠在品牌色浅底上显示。

- `wecom.png`：企业微信官网 `https://work.weixin.qq.com/` 的 48×48 favicon。
- `dingtalk.png`：钉钉官网 `https://www.dingtalk.com/` 的 favicon。
- `feishu.png`：飞书国际版 Lark 官网 `https://www.larksuite.com/` 的 favicon，飞书和 Lark 用的是同一个标志。

品牌图标仅用于标识对应平台，不表示这些平台已经连接或可用。
