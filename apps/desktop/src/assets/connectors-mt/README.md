# 推荐连接器图标

本目录供 HexAgent 风格的桌面推荐连接器目录使用。

- `amap.png`、`ima.png`、`netease-mail.svg`、`qq-mail.png`、`wecom.png`、`wps.png`、`youdao-note.png`：迁自本机 HexAgent 的 `libs/hexagent_demo/frontend/src/assets/connectors/`。
- `qcc.svg`、`eastmoney.svg`、`ifind.svg`：迁自同项目 `ConnectorsPage.tsx` 的品牌图形；转换为独立 SVG，保留原图形。
- `aminer.png`：HexAgent 使用的同一官方图片 `https://fileserver.aminer.cn/sys/aminer/product/AMinerIcon_Open.png`，改为本地加载。

品牌图标仅用于标识对应服务，不表示这些服务已经连接或可用。
