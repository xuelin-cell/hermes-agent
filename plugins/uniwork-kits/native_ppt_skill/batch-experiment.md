# 可选批量实验（不作为默认路线）

只有用户明确要求批量或对照测试时使用。默认仍沿用WorkBuddy v20261013逐页生成与反馈。

1. 先确定同一份DESIGN.md、内容大纲及所需素材。一个.slide只含一页；一次准备2至3页，工具最多接受4页。不要同时向同一PPT发起写操作。
2. 用write-pages(file_path=工作稿,dsl_files=[已保存的独立源文件绝对路径,...])。宿主串行执行每页write-page（写入→lint）；各页仍检查，不减少检查步骤。
3. 返回失败立即处理failed_source和page_index；只改失败页，再重试。保留源文件路径与页序，不重建空稿、不换名追加；已通过且源文件和成品页未变的页可复用。
4. 批内素材与设计保持不变。修改被引用图片、主题或外部依赖时，即使.slide未变，也应以write-page和原page_index重新写受影响页，不依赖批量的源文本复用。
5. 成功后读取本批回执再生成下一批。计划页数全部完成后finalize一次；工具失败、缺图或检查失败不能冒称完成。

批量节省的是模型调用往返，不减少原生写入和检查次数。尚无稳定的速度或质量优势保证。对照实验使用相同模型、需求、附件与质量标准，分别记录模型等待、工具耗时、重试、页面内容与渲染质量；不能把同一源文件的机械写入测试等同于模型生成质量对照。
