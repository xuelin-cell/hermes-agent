# 投资分析 · 研究报告

> 场景：面向投委会、路演、基金内部讨论、买方尽调的深度研究 deck。
> 触发关键词：投资分析、研究报告、行业研究、公司深度、估值报告、券商研报、投资备忘录、投研 deck、买方尽调、行业深度。

---

## 一、定位

读者是分析师、PM、投委会——允许较高信息密度，重视数据、比较、推导与假设。

读者要能看清四件事：**判断是什么、证据在哪里、如何推导、在什么条件下成立**。漏"判断"是信息板，漏"证据"是宣传册，漏"推导"是黑箱，漏"条件"是承诺。

---

## 二、整体写作的逻辑

### 行文风格

- **判断要明确，但要承认不确定性**：给目标价、提方向，同时说清"基于什么假设、哪里可能错"。少了后半截就是推销。
- **具体压倒抽象**："毛利从 35% 降到 28%" 比 "盈利能力下滑" 有信息量。形容词越多，可信度越低。
- **克制地表达**：避免"卓越""领先""完美""显然""毫无疑问"这类自我褒奖或武断的词；用"倾向于认为""从数据看""在 X 条件下""可能"等贴近证据的句式——靠证据说话，不靠语气。
- **写给同行**：不解释金融常识，不堆砌术语。该用 ROIC 就用 ROIC。

### 论述方法

- **先有判断，再有证据**：页题是完整判断句（最好带数字），不是关键词。别写"医美市场规模"，写"年规模 1000 亿，主要增长来自美容心智提升"。副标题一句展开说明为什么这么判。章节页和目录页可用主题标题。
- **数字要落在判断上**："2024 年销量增长 16.3%" 是摘录，不是分析——研究动作是找出背后原因，说明这个数字意味着什么、接下来该怎么办。
- **证据要留痕**：每个数字都能反查（正文角标 + 底部脚注 + Source）。
- **四种信息分开讲**：披露事实（公司披露，受法律约束）、测算（你从公开数据算的）、预测（基于假设推的）、研究判断（你自己的观点）——看起来都是"数据"，可信度差别很大。
- **论点对应可验证的条件**：投资论点对应可验证的指标、事件或失效条件，不是承诺。

### 硬禁止

- **内容过空**：一页三句话加一张大图、留一大片白，是路演 deck 的做法，不是研究报告的做法。
- **卡片感容器**：要避免的是"大圆角 + 明显阴影 + 饱和色块底"这套**组合**（SaaS 产品页 / App 落地页的视觉语言）——单个容器不要做得像一张浮起的卡片。
- **AI 味表达**：形容词堆砌的卖点式标题（"卓越表现""行业领先""重大突破"）、对称罗列的 SWOT / 三大优势 / 五大趋势、万能句式（"随着 XX 的发展，YY 面临新的机遇与挑战"）、emoji 与感叹号。
- **均分构图**：左右 50:50、四宫格、五等分卡片意味着没有主次。用 60:40、65:35、7:3 这类非对称，把"哪个更重要"摆给读者看。

## 三、常见的分析模块（举例）

不是每份 deck 都要覆盖所有模块，也不必按这个顺序——讲什么取决于要回答什么问题。

**行业**：产业链各环节的定位、发展阶段、竞争规则。
**市场规模**：现在多大（含口径）、增速多少、增长由什么驱动。
**公司业务**：过去几年做了什么、扛过什么周期，比现在讲想做什么重要。护城河要能验证。
**产品 / 管线**：具体产品线（在研 / 储备 / 上市），各自的收入、增速、市场预期。别写成产品说明书。
**竞品与对标**：主要玩家各自的着力点、做得怎么样、凭什么。选谁做对标本身就是分析动作。
**财务与估值**：历史财务质量 → 盈利预测 → 估值定价。敏感性比目标价重要。
**其他**：宏观与政策、催化剂与风险跟踪、组合配置、退出路径——要不要放、放多少页，取决于这份 deck 为谁写。

## 四、容器组件（文字载体）

**核心原则**：**尽量少用大片裸露的长段文字**——任何超过 2 行的正文段落（结论、测算、口径、假设、风险、研究判断等）**都应该放在容器里**，让读者一眼看出"这是一个独立信息块"。

研报的克制美学 **≠ 文字裸奔**。真正的克制是**容器本身克制**：没有阴影、没有大圆角、没有饱和色底——但该有的边界、分组、层次一个不少。

### 4.1 容器白名单

#### ① 细描边 box

**样式**：1px 浅灰边框（如 `#D5D9DF` / `#E0E3E8`）+ 白底或极浅底 + **6-8px 小圆角** + padding 内留白 ≥ 16px。
**结构**：顶部一行主色小标题（14-15px 加粗）→ 下方正文内容。
**用途**：承载**常规正文段落**——测算说明、口径解释、研究判断、分析展开，是研报的默认文字载体。
**什么时候用**：绝大多数超过 4 行的段落都该用这个。

#### ② 带 icon 分段 box

**样式**：同①的细描边 + 白底 + 小圆角 + 无阴影，内部列 3-5 条带 icon 的分段。
**结构**：

- 顶部一行主色小标题（如"困境不在算法，而在供给"）
- 每条分段：主色线性 icon（16-20px，线性克制，禁彩色/立体/面性）+ 加粗小标题（14-15px）+ 下方灰色说明文字（12-13px，1.5 倍行距）
- 条与条之间间距 12-16px
  **用途**：**要点清单**——"X 大问题 / 机遇 / 策略"类并列结构、关键矛盾分点。
  **纪律**：条目数 3-5 条，少于 3 条用普通 box，超过 5 条拆成两列或换表格。

#### ③ 主色强调卡

**样式**：**深主色实底**+ **白字反白** + 4-6px 小圆角 + 无阴影 + padding ≥ 16px。
**结构**：顶部加粗小标题（如"我们的判断""核心结论"）→ 下方正文。
**用途**：**整页唯一的关键判断/核心观点/我们的结论**——通过深色反差把读者眼球强行拉到这一个块。
**铁律**：

- **一页 ≤ 1 个**，否则深色反差被稀释，变成装饰
- 只放结论性短段落（≤ 4 行），不放长分析
- 深色底必须是 scenario 主色或接近主色的深色，禁止用无关的黑/灰/其他色

#### ④ 虚线框

**样式**：1px dashed 浅灰边框 + 无底或 2-3% 极浅底 + 4px 圆角 + 无阴影 + padding ≥ 12px。
**用途**：**次要补充**——补充口径、脚注说明、"值得关注的变量"、辅助假设。虚线暗示"这是补充不是主干"，让读者视觉上自动降权。
**不要用于**：核心结论、关键数据（这些该走①或③）。

#### ⑤ 顶线分区（无边框）

**样式**：段落上方 1px 主色实线（宽度 = 段落宽度）+ 顶线与段首间距 4-6px + 无边框 + 无底色。
**用途**：**小节起始 / 章内分组** —— 用一根细线分区，比 box 更轻量。
**什么时候选这个**：一页里已经有 ①②③ 的容器了，想再分一个小组但不想堆更多卡片时。

### 4.2 容器黑名单（严禁）

- ❌ **阴影**：任何扩散投影、叠层光感、玻璃拟态——这是 SaaS 卡片的标志，研报气质和它冲突
- ❌ **装饰性边框**：花纹、斜线、渐变边框、双层边框、虚线+实线混用
- ❌ **彩色/立体/面性 icon**：icon 必须是单色线性，禁彩色、禁立体、禁 emoji 风面性

### 4.3 使用纪律

1. 较长正文段落最好都用容器包裹
2. **一页容器密度**：
   - 普通内容页同类容器 ≤ 3 个（防止卡片堆砌）
   - ③ 深色强调卡**一页 ≤ 1 个**（铁律）
   - 不同类型容器**可以组合**，但组合不超过 3 种
3. **容器类型一致性**：同一功能（如"结论"、"测算"、"风险"）在**全文中用同一容器样式**，不要这页描边、下页虚线框，否则 Agent 像在随机发挥
4. **禁嵌套**：不要 box 里再套 box，想分小块就用网格 / 竖线分割 / 顶线分区
5. **容器内 padding**：左右 ≥ 16px，上下 ≥ 14px，正文不得贴边
6. **边框色统一**：全篇只用一种边框灰（如 `#D5D9DF`），不同页不要换色
7. **圆角统一**：全篇只用一档圆角（4px 或 6px 选一档），不要混


## 五、页面布局：13 类排布

规划页面时可以**按本页的论证任务选择或组合**。这 14 类是布局参考库，不是必填目录，也不要求每页包含所有组件。

分工要清楚：**图表用于看关系与趋势，表格用于查数值与比较**。二者同时出现时分工明确；突出关键系列、目标公司或基准情景，避免所有元素同等醒目。

**表格不要设底色**：表格自身保持透明，让页面底色透出来。否则一旦页面不是白底，表格就会突兀地浮在上面。需要突出重点行时，改用**加粗文字**或**上下边框线**来标记，不要用行底色填充。

**结构先于内容**：无论一页多复杂，都要让人一眼抓到重点、一眼看懂这页怎么布局——主证据在哪、结论在哪、注释在哪，位置明确、有层级。最忌讳内容堆得多却杂乱无章：东一块图、西一块结论，读者看完不知道看哪儿。动手前先定结构（这页分几块、每块负责什么），再往里填内容。

**非对称优先**：下面 13 类排布是骨架，实际用的时候要**主动打破规整**——不要每页都是左右两列或上下两分的对称结构。宽窄比优先用 60:40、65:35、7:3；主证据（主图、主表、关键数字）占大区，解读和注释占小区。**全篇非对称版式应占多数**，对称构图（如"上下两区等分"）只在少数页面使用。

**非对称 ≠ 错位**：上面的"非对称"指的是**区块宽度比例不等**，不是元素可以随意错落。所有区块仍要对齐到统一网格——**左边缘对齐同一条竖线，并列的区块顶边齐平、底边齐平**。禁止出现"一块高一截、一块低一截"的参差感：**宽窄可以不等，边缘必须整齐**。

| **8. 竞争格局与竞品对标页：谁在场上，各自强在哪，我们处于什么位置** | ①**竞品概览**：列出主要玩家，每家讲清**定位、主营、体量**（营收／份额／用户数等）。用竞品介绍表或并列卡片呈现——**选谁做对标本身就是分析动作**，需业务重叠、区域或阶段可比，不能随手抓几家。② **维度对比**：规模、增速、市占、盈利、获客等。③ **关键结论**：落在两件事上——**本公司在市场中的身位**（第一梯队／跟随者／差异化玩家，份额多少，领先或落后于哪些维度），以及**身位背后的原因与后续要看的变量**。口径说明紧随表格。有余量时可加二维定位图展示市场分布，不够就省略。                                                                                                                                                                  |
| **9. 竞争优势页：优势怎么来的，怎么证明，能持续多久**               | **承接上一页**——第 8 页说清「我们在什么位置」，这一页回答「凭什么能守住这个位置」。三段论证链：① **优势机制链**：串起「**资源／能力 → 客户或成本效果 → 财务结果**」，每条一个小标题 + 一句说明。**优势必须落到可验证的指标**（毛利、留存、获客成本、资本回报），说不到指标的优势都是形容词。② **证据验证**：用同业对比图或长期趋势图验证每条优势，图放在对应论点旁边——**图是跟着论点走的，不是堆在一起**。③ **边界区**：说明优势依赖什么条件、哪些变化会削弱它。版面同第 8 页：论证区靠左，结论区放不对称位置（底部／右侧），细线或留白分区，                                                                                                |
| **10. 历史财务与质量页：过去赚了多少、钱怎么没的、回报质量如何**    | 这是估值论证的起点。①**经营结果**：核心指标带概括收入、利润、经营现金流、ROE/ROIC 的历史表现，图表展现主要变化。② **损益拆解**：用瀑布图展示收入到净利润的扣减过程，标出边际贡献和经营损益两个关键节点，说明盈亏来自哪里。③ **资本质量**：钱怎么用的——再投资、并购、分红、回购，各自带来什么回报。对判断管理层重要时展开，否则一张配置表 + 一句话带过。**结论句**：历史利润是不是「真」的、增长是不是健康的、管理层的钱有没有花在刀刃上——下一页做预测时才能知道哪些可持续、哪些不能。                                                                                                                                                                            |
| **11. 盈利预测页：未来 3-5 年赚多少，基于什么假设**                 | 承接第 10 页的历史质量，做前瞻外推。①**驱动树**：收入拆成量 × 价、成本拆成固定 + 变动，说清每个变量怎么推导——**哪些是外推历史趋势，哪些是基于新假设**。② **预测表与多情景曲线**：历史和预测用线型（实线 vs 虚线）或底色区分；给基准、乐观、悲观三档，基准情景加粗高亮。③ **关键假设摘要**：列出 3-5 条最关键的假设及其出处（行业数据、公司指引、研究判断），说明**哪个假设最脆弱**——这决定下一页估值区间的宽度。                                                                                                                                                                                                                                          |
| **12. 估值与定价页：公司值多少钱，当前价格隐含了什么**              | 把预测转化为价值区间。①**估值方法与依据**：DCF、可比公司、交易乘数——按业务特性选择，说清为什么用这个方法（成熟稳定现金流用 DCF，可比样本充分用相对估值）。② **价值区间图**：如用多种方法，集中汇总价值区间，并标出当前股价位置——**一眼看到隐含上下空间**。③ **敏感性矩阵**：核心假设变化前后的估值结果，表格形式；基准情景加粗。**结论句**：当前价格对应多少预期（PE、EV/EBITDA、隐含增长率等），这个预期是不是合理。                                                                                                                                                                                                                                      |
| **13. 风险、催化剂与跟踪页：怎么验证判断，什么时候知道错了**        | 独立于估值——**估值告诉我们该买多少，这页告诉我们什么时候止损**。① **催化剂时间轴**：时间明确的事件按时间轴排列，每个节点说明验证内容（财报季度、新产品发布、政策落地等）。② **跟踪指标表**：按论点列出观察指标、预期值、触发阈值——**超过阈值就是信号**。③ **风险情景**：核心论点如果错了，股价下行空间多少。极端场景做压力测试。**结尾**：近期要紧盯的 2-3 件事，让读者带着明确的观察清单走出会议室。                                                                                                                                                                                                                                                |

## 六、色彩与字体

### 6.1 使用原则

**配色克制是研报的质感**。真实研报的面积比例大致：底色 ≥ 70%、正文约 20%、主色（章节线/图表第一系列）5-8%、辅助图表色（第二系列/浅色背景）2-3%、分隔/底轨（细线/表格边框）1-2%、强调色（关键结论/我方公司）**≤ 2%**。

**强调色是稀缺资源**：一页最多出现 2-3 次，只用于语义位置（我方公司行、估值基准情景、瀑布图最终盈亏节点），不用于章节线、页脚、页码等结构元素。**不滥用强调色是投研 deck 掉档最快的防线**。

**跨页一致**：同一公司、情景或指标跨页保持同色；涨跌、风险、预测含义保持一致，辅以标签/线型/符号区分。

**层级靠字号字重**：H1/H2/正文统一用"正文色"，靠字号和字重拉层级，不额外设独立标题色——这是真实研报的做法。

**字体**：中文以思源黑体、微软雅黑做正文与图表，思源宋体做研究刊物感的标题，楷体／楷体_GB2312 用于政策解读、专家观点、导语或较短正文。英文与数字用 Arial（通用）、Aptos（现代商务）或 Georgia（章节标题和观点引述）；密集财务表格优先 Arial 或 Aptos，数字统一小数位并右对齐。默认搭配思源黑体 + Arial；要中文研究稿气质就上楷体标题 + 思源黑体正文 + Arial 数字。整份报告保持少量字体和稳定字重层级，交付前检查字体替换。

## 七、版面纪律与完成检查

### 7.1 版面密度（硬规则）

画布 1280×720；左右安全边距 40，内容区宽 1200。

投研是阅读型 deck，**密度就是质感**。以下为硬规则：

1. **内容区铺满**：正文页内容区累计高度 ≥ 540px（与 `design-principle.md §1.3` 对齐；内容区 600px 的 90%）。留白明显过大即不合格。
2. **禁止空容器**：任何卡片 / 面板 / 分区框都必须有内容。渲染出来是空的就删掉——空白容器比没有更难看。
3. **纵向填满**：底部空白 ≤ 一个卡片高度。超了说明内容不够，**去补内容（补数据、补解读、补口径），而不是把元素往上缩**。
4. **左右底对齐**：分栏时两栏底部对齐，高度差 ≤ 8px；禁止一栏到底、另一栏空半截。
5. **间距两档制**：块间距只用 24px（紧密）和 32px（宽松）两档；同层级用同一档，禁止 16/20/28 随手混用。
6. **禁止元素居中聚集**：内容不得全挤在页面中央 60% 区域、四周空一圈。
7. **密度不够补内容，不补装饰**：缺数据补数据、缺解读补解读；严禁靠放大留白、加色块、加装饰图形把版面撑开。
8. **区块边缘对齐**：同一区域内的多个区块，左边缘对齐到同一条竖线；并列的区块顶边齐平、底边齐平。**禁止参差不齐**。
9. **同级间距相等**：同一层级的元素之间间距必须一致（24px 或 32px 选一档，全篇统一）；禁止忽紧忽松、随手给值。
10. **留白要收敛**：留白只作为区块之间**均匀的间隙**存在。不要出现"几块内容夹着一大片空洞"——看到大空洞说明内容不够，去补内容，不是留着当设计。
11. **跨页对齐一致**：不同页面的同类元素（页标题位置、正文左边缘、底部脚注线）位置保持一致，翻页时不能左右跳。

### 7.2 完成检查

**内容层面**：每页标题是否由证据支持？关键数字的口径、单位、时期是否清楚？预测和估值的关键假设是否写明？论点是否对应可验证的指标或失效条件？披露事实 / 测算 / 预测 / 判断四种信息是否分开讲？

**视觉层面**（生成实际页面后再查）：有无文字溢出、重叠？图表标签和来源是否可读？跨页字体、配色、对齐是否统一？同一对象（公司/情景/指标）跨页颜色是否一致？**表格是否误加了底色**（应为透明）？

**对齐专项**（逐页扫一眼）：区块左边缘是否在同一条竖线上？并列区块顶边／底边是否齐平？有没有"一块高一截、一块低一截"的参差？同级元素间距是否相等、有没有忽紧忽松？有没有夹着大块空洞的留白？翻到下一页时，标题和正文的左边缘有没有左右跳？
