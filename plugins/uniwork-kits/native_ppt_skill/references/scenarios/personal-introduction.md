# 个人介绍

> 场景：自我介绍、人物介绍、嘉宾介绍、读书会、纪念专题、作品集介绍
> 触发关键词：自我介绍、个人简介、人物介绍、嘉宾介绍、履历分享、作品集

---

## 一、整体理念

**三条核心倾向**，决定了什么样的布局更可能让 PPT 好看：

- **不规则 > 规则**。错落、重叠、非对称、微旋转——比均分卡片矩阵好看十倍
- **组件复杂 > 组件单一**。一张照片 + 便签 + 签名 + 标签叠在一起，比一张照片居中好看
- **节奏感 > 等密度**。满版的后面接留白，密集的后面接高潮——像一首歌，不是会议纪要

### 共同原则

1. **具体代替形容**。"擅长沟通" → "主导过 12 场 500+ 人分享"；"喜欢阅读" → "最近在读加缪《鼠疫》"。事情本身在证明品质
2. **要有节奏，不要均匀**。履历页密、引言页空、高潮页冲——像音乐，不是文档
3. **只放跟"这个人"真的相关的东西**。封面不放风景、作品页不放素材图、兴趣页不堆通用图标。素材不够就留白，不拿无关图凑

- **不要均分卡片矩阵**（2×3 爱好卡、2×2 履历卡）

- **不要 emoji / 装饰 icon**（🚀💡⭐️ 一出现就降级为短视频文案）
- **不要空泛品质词**（擅长沟通 / 学习能力强 / 团队合作）
- **不要简历罗列风**（履历只有"公司 + 职位 + 年份"，不讲做了什么）
- **不要封面放风景 / 抽象纹理 / 通用素材图**

介绍他人时另加：**不要把评价当原话**——原话必须标出处（哪本书、哪次访谈、哪一年）。

## 二、三种调性

同样是"个人介绍"，气质差别很大。下面三种调性只是**参考坐标**，实际做的时候可以在光谱上滑动——比如一位严肃学者可以借用一点创意型的布局，一位设计师也可以收一点走正式。

| 调性           | 气质                   | 典型场合                                    | 布局总体倾向               |
| -------------- | ---------------------- | ------------------------------------------- | -------------------------- |
| **正式** | 克制、规整、信息密集   | 求职面试、学术介绍、商务引荐、述职          | 对齐规整为主，少量错落点缀 |
| **创意** | 大胆、非对称、照片主导 | 设计师 / 艺术家作品集、纪录片人物、杂志专访 | 满版 / 拼贴 / 重叠 / 蒙层  |
| **生活** | 亲和、轻盈、有手写感   | 新员工迎新、分享会开场、读书会破冰          | 剪贴簿、便签、生活照拼贴   |

## 三、布局候选池（**核心**）

下面按**页面功能**分组，每组给 3-7 个风格差异明显的候选布局。AI 根据下面几件事自主决定每一页用哪一个：

- **主角调性**（正式 / 创意 / 生活）决定该优先哪些候选
- **素材优先级**：主角本人照 > 作品 / 项目照 > 真实场景照（他工作 / 生活的照片）。先从用户提供的素材里取，缺则联网搜。找不到合适照片时走大字 + 留白，**不要用风景、纹理、通用素材图凑数**
- **整体节奏**：全篇避免同类布局连用，封面 - 身份 - 履历 - 作品 - 高潮 - 结尾之间应该有张弛

**鼓励挑复杂 / 不规则的那几个**——除非主角明确是 正式 职业正式型且素材偏少。

### 3.1 封面页（7 个候选）

| #           | 名字            | 风格描述                                                                                                             | 适合调性  |
| ----------- | --------------- | -------------------------------------------------------------------------------------------------------------------- | --------- |
| **a** | 人像蒙层式      | 整页人像铺满，上压由底向上渐变的深色蒙层，姓名大字叠在蒙层下部。Netflix 纪录片片头的感觉                             | 创意 生活 |
| **b** | 杂志对页式      | 左 2/3 是人像出血，右 1/3 浅色文字区（刊头小字 → 姓名大字 → 标语 → 底部目录提示）。像《Monocle》《纽约客》封面    | 创意      |
| **c** | 正经居中式      | 姓名居中偏上，大字黑体，下方跟职业和所属，角落放一张得体工作照（圆形或方形带细描边）。像律所合伙人页                 | 正式      |
| **d** | 大字 + 极小照片 | 整页只有超大姓名（180-240px）占据画面，右下角贴一张小小的证件照（约 100×100），四周大面积留白。有一种"反差感"的高级 | 正式 创意 |
| **e** | 作品墙封面      | 封面不放人像，放作品拼贴——3-5 张代表作重叠排布，姓名用小字叠在角落。适合"作品说话"的主角                           | 创意      |
| **f** | 手写签名式      | 浅色底 + 大字姓名（衬线或手写字体）+ 下方真实手写签名（扫描或模拟）。亲和、有温度                                    | 生活 正式 |
| **g** | 一句话封面      | 全页只有一句自我定义（如"我做了 10 年产品，想和你聊 15 分钟"），大字居中，右下角小字签名。省掉所有装饰               | 创意 生活 |

| #           | 名字            | 风格描述                                                                                                                                                                        | 适合调性  |

### 3.3 履历 / 时间轴页（5 个候选）

| #           | 名字                             | 风格描述                                                                                                                                                                                           | 适合调性  |
| ----------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| **a** | 规整纵向时间轴                   | 中轴线贯穿，年份节点均匀挂在轴上，右侧跟同款事件卡——等宽、顶底对齐。追求的就是规整。像博物馆大事年表                                                                                             | 正式      |
| **b** | 艺术树状时间轴（**推荐**） | 抛弃中轴线，节点大小不一散落——大作品照微旋转带阴影作主果实、中照片 2-3 张散布中段、纯文字节点自由摆放、感悟卡放角落。用 SVG 淡色曲线连接。整体有流动方向（左上 → 右下）。像艺术家个展的"生平墙" | 创意 生活 |
| **c** | 横向时间带                       | 水平时间线从左贯到右（可轻微斜向上暗示成长），事件卡交替挂在时间线上下方（上-下-上-下）。错落而不散乱                                                                                              | 正式 创意 |
| **d** | 阶段跳跃页                       | 不按年份走，按"阶段"走——学生时代 / 第一份工作 / 转折点 / 现在，每段用大标题 + 一张照片 + 一句话。可以竖排堆叠或分区排布                                                                          | 创意 生活 |
| **e** | 日记页式                         | 像翻日记——每段履历用手写字体标题 + 一张随手拍的照片 + 一段短文字描述。排布可以散、可以有折痕感                                                                                                   | 生活      |

| **a** | 剪贴簿拼贴（**推荐**） | 页面散落布置——2-3 张生活照（不规则角度、带白色相框）、1-2 张票根 / 便签 / 日记纸条（半透明贴在照片边缘）、2-3 个关键词便签（手写字体微斜）、1 段手写字体小段落。浅色底、细节丰富。像少年时期的剪贴簿、Pinterest 情绪板 | 生活 创意      |

| **c** | 一句独白          | 整页纯色底 + 一段 2-3 行独白（而不是单句引用），字号 40-60px，像自语。周围大量留白                                                      | 正式 创意      |

## 四、怎么组合与选择

一份 8-15 页的介绍，不是从每个功能里都挑一页，而是挑**最能讲清这个人**的 5-8 页。

**几条组合原则**：

1. **调性大致统一**。整份介绍 70%+ 的页面来自同一调性（正式 / 创意 / 生活），避免每页跳 tone。但**允许故意借用一张异质布局做对比**——比如全篇 正式 职业正式型，突然出现一张 创意 创意型满版人像作高潮，反而出彩
2. **避免同类布局连用**。两页履历不要都用同一种时间轴，两页作品不要都用拼贴重叠——节奏感来自对比
3. **至少 1-2 页高潮**。一份介绍如果全是中等密度，等于催眠。高潮页（§3.6）必须有，位置建议：中段 1 页 + 结尾前 1 页
4. **优先挑复杂 / 不规则候选**。本文档里**标注"推荐"的候选都是复杂度更高、更不规则的**——它们更可能让 PPT 好看。除非：
   - 主角明确是 正式 调性
   - 素材不够（没有大照片、没有多件作品）
   - 本页承担的是信息密集任务（履历查读、能力清单）
5. **素材决定上限**。有真实大照片 → 用满版、拼贴、蒙层；没照片 → 走大字 + 留白、关键词云、档案卡

**几种常见组合示例**（供 AI 参考，不是必须）：

- **正式 学术个人介绍（10 页）**：封面 c + 定位 b + 履历 a + 作品 b + 作品 e + 能力清单 + 引言 a + 结尾 a
- **创意 设计师作品集（12 页）**：封面 a + 定位 d + 履历 b（艺术树状）+ 作品 a + 作品 c + 作品 a + 高潮 a + 高潮 b + 兴趣 b + 引言 b + 结尾 b
- **生活 新员工破冰（8 页）**：封面 f + 定位 c + 履历 e + 兴趣 a + 高潮 a + 结尾 c

## 五、配色与字体（放最后）

### 5.1 可参考的配色

个人介绍配色较为丰富自由，可根据这个人的职业和背景确定相关色彩。确定主色底色辅色正文色后，一份介绍只用一套。禁用：彩虹渐变、荧光色、糖果色全家桶。

### 5.2 字体（按气质选一组）

- **沉稳职业**：思源宋体标题 + 思源黑体正文；英文 Georgia / Times
- **现代专业**：思源黑体 / OPPO Sans；英文 Inter / Helvetica
- **文艺克制**：思源宋体 / 方正悠宋；英文 Playfair Display / Baskerville
- **极客设计**：思源黑体 Light；英文 JetBrains Mono（等宽）
- **生活轻盈**：思源黑体 + 手写字体点缀（姓名、标语、便签处）

全篇不超过两种字体家族。用户自带字体（哪怕楷体、仿宋、手写体）要尊重。

### 5.3 字号参考

| 用途         | 字号      |
| ------------ | --------- |
| 封面姓名     | 100-180px |
| 高潮页大数字 | 180-280px |
| 引言 / 标语  | 40-60px   |
| 页主标题     | 36-48px   |
| 卡内小标     | 22-28px   |
| 正文         | 20-24px   |

## 六、完成检查

- 整份介绍大致属于哪个调性（正式 / 创意 / 生活）？70%+ 的页面是不是来自该调性？
- 有没有**至少 1-2 页高潮**？
- 相邻两页有没有重复用同类布局？
- 本来可以用复杂 / 不规则候选的地方，是不是偷懒用了简单候选？
- 封面用的照片真的跟"这个人"相关吗？不是风景、抽象素材、通用图？
- 履历页 / 作品页 / 兴趣页**有没有陷入均分卡片矩阵**？
- 有没有空泛品质词需要换成具体的事？
- 介绍他人时，评价和原话分清了吗？引言是否标出处？
