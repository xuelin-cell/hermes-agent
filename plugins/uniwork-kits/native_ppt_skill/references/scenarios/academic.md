# 学术研究报告

> 核心判据：**汇报自己的研究成果**——讲"我研究了什么、发现了什么"。
> 场景：开题 / 中期 / 答辩 / 结题、文献综述、学术会议报告、研讨课汇报、课程研究报告、学术读书报告、科研课题进展。
> 触发关键词：开题报告、中期检查、答辩、结题、文献综述、学术会议、研究进展、读书报告、课程研究报告。
>
> **不包括教学课件**：老师授课用的课件 / 讲义——目的是"教别人学会某个知识点"（讲别人的知识），不是汇报自己的研究。这类走通用场景 `general.md`。

## 一、学术版式的遵守

学术报告的使用者通常隶属某个学校、学院、研究中心、学术团体——**他们有既定的 PPT 风格**。版式应该**先对齐组织，再谈创作**。

### 1.1 优先：确认用户所在组织的风格

动手之前，先尝试确认（按顺序）：

1. **用户是否指定了学校 / 机构**（如"复旦大学经济学院""XX 实验室"）——向用户确认该组织是否有标准 PPT 模板、品牌色、Logo
2. **用户是否能提供参考材料**——以往同类报告、学院模板、机构品牌手册、校徽矢量
3. **以上都没有，但有明确组织归属**——根据组织名称尝试搜索其官方视觉识别系统（主色、Logo、学院旗帜色、建筑色调是常见线索）

**确认时要拿到的要素**（按 1.2 的槽位对齐，拿到几项就用几项，缺的部分走兜底）：

| 槽位                | 对应来源                                                                               |
| ------------------- | -------------------------------------------------------------------------------------- |
| **主色**      | Logo 主色 / 校徽主色 / 院系旗帜色                                                      |
| **辅色**      | Logo 第二色 / 配套色板里的次色                                                         |
| **强调色**    | 组织本身很少定义，缺就用兜底的警示红`#D9534F`                                        |
| **正文色**    | 组织规范里的正文灰黑；没有就用`#1A2230`                                              |
| **底色**      | **一般是白色 `#FFFFFF`**——学术场景的底色默认白，除非组织明确要求深底或暖米底 |
| **Logo 文件** | 封面、页脚右下角要用                                                                   |
| **字体建议**  | 组织规定了就跟（哪怕是楷体、仿宋等非常规选择，也遵守）                                 |

找到的部分**原样沿用，不自作主张**；没找到的部分走 1.2 兜底。**底色的默认是白**——如果用户给的模板是深蓝底或深色底，可以保留，但要意识到那是组织的特殊选择，不是学术场景的默认。

### 1.2 兜底：学术宝蓝 + 白底

1.1 的要素没拿齐、或完全没有组织归属时，用下面这一套贯穿全篇——这是最接近真实答辩 / 开题 / 中期汇报现场的配色。

| 槽位                     | Hex                                     | 名称                                 | 面积占比                                                        |
| ------------------------ | --------------------------------------- | ------------------------------------ | --------------------------------------------------------------- |
| **主色**           | `#1E4FA8`                             | 学术宝蓝                             | 15-25%（顶条、编号块、章节号、强调）                            |
| **辅色**           | `#3D7BD9` / `#E8EFF8`               | 中蓝 / 浅蓝                          | 5-15%（描边、图表第二色、卡底、信息横幅底）                     |
| **强调色**         | `#D9534F`                             | 警示红                               | **≤ 3%**（关键发现、异常值、风险。全篇稀缺资源，不乱用） |
| **数据黄**（可选） | `#FFC107`                             | 数据黄                               | **≤ 3%**（图表第二序列、核心金句高亮）                   |
| **正文色**         | `#1A2230` / `#4A5568` / `#8B97A8` | 深墨 / 中灰 / 浅灰（主 / 副 / 辅助） | 约 20%                                                          |
| **底色**           | `#FFFFFF`                             | **白**（学术默认）             | **≥ 60%**                                                |
| 辅底（可选）             | `#F7F9FC`                             | 极浅蓝灰                             | 0-15%（局部卡片底、表头底，不作主底）                           |
| 分隔 / 线框              | `#D6DCE5` / `#E5E7EB`               | 极浅灰                               | 1-2%（卡片描边、表格分隔线）                                    |

**底色优先用白** `#FFFFFF`——学术报告的默认就是白底，不要换成米色、暖纸、深色。深蓝顶条配白内容区的对比，是这套配色最经典的学术感来源。

**几条占比纪律**：

- 蓝族（主色 + 辅色）合计 20-40%，不要全页都是蓝
- 白底 **≥ 60%**，不要用大色块把白底吃掉
- 红 + 黄合计 **≤ 5%**，强调色是稀缺资源
- **金色 = 0**（金色是政务 / 党政的语言，不是学术）
- **禁色**：紫、粉、玫红、橙绿大色块、彩虹渐变、纯黑大底

### 1.3 字体

- **中文**：**全篇以思源黑体为主**。标题、正文、图表标签、公式说明都用思源黑，通过字重和字号拉出层级，不要混入宋体。思源宋体 / Times New Roman 只在两种情况下出现：**封面英文长 title**、**长段引文**。
- **英文与数字**：正文和表格用 **Arial**（数字统一小数位、右对齐）；章节扉页的大数字可用 **Georgia** 或 **Times** 增加厚重感。
- 整篇不超过两种字体家族，字重层级稳定（Regular / 600 / Bold 三档够用）。

### 1.4 字号阶梯（画布 1280×720）

| 层级                           | 字号              | 字重               | 用途                                                              |
| ------------------------------ | ----------------- | ------------------ | ----------------------------------------------------------------- |
| 封面中文主标                   | 54-72px           | Bold               | 封面唯一主标                                                      |
| 封面英文长 title               | 40-56px           | Bold（Serif 可选） | 封面副标式英文长标题                                              |
| 章节扉页大数字                 | 120-280px         | Bold               | 章节扉页 01 / 02 / 03 等                                          |
| **页主标题（顶条白字）** | **32-40px** | Bold               | 每页顶条里的主标题                                                |
| 副标题 / 章节英文名            | 18-22px           | Regular / 600      | 顶条右侧的英文章节标识                                            |
| 卡内小标题                     | 22-28px           | Bold / 600         | 多卡页的每张卡标题                                                |
| **正文**                 | **20-24px** | Regular            | 卡内正文、段落；比旧版（14-16pt）明显放大，才是答辩真实可读的字号 |
| **KPI 巨数字**           | **64-96px** | Bold               | 关键数据强调（三联数、单核心数据）                                |
| 表格                           | 16-20px           | Regular / Bold     | 表头 Bold，表体 Regular                                           |
| 图表标签 / 轴                  | 14-16px           | Regular            | 图表内文字                                                        |
| 注释 / 引用 / 页脚             | 12-14px           | Regular            | 来源、脚注、页码                                                  |

**几个硬下限**：正文**不低于 20px**，卡内小标题**不低于 22px**，顶条主标**不低于 32px**。文字对比度 ≥4.5:1——深蓝底必须配白字，白底配深蓝 / 深灰。

## 二、学术研究内容

### 2.1 行文风格

- **平实优先**：学术研究不需要形容词和修辞。用准确的术语、完整的句子、清楚的逻辑。避免"重大突破""深远影响""开创性地"这类词。
- **论断要有依据**：每一个观点后面跟着文献、数据或推导。没有依据的判断就是猜测，要标明是推测。
- **诚实报告局限**：研究有什么不足、数据有什么限制、结论适用什么范围——写出来比藏着更专业。
- **写给同行**：不解释学科常识，不堆砌术语。该用专业术语就用。

### 2.2 硬禁止

- **编造引用和数据**：参考文献必须真实存在；数据必须来自真实来源或自己的实验/调研。公式必须可追溯到教材或论文。**这是学术报告最不能碰的红线。**
- **AI 味表达**：卖点式标题（"重大突破""开创性"）、对称罗列（三大创新/五大贡献）、万能句式、emoji 与感叹号。
- **内容过空**：一页几句话加大片留白，不是学术报告的做法。
- **卡片感容器**：避免"大圆角 + 饱和底色 + 明显阴影"的浮起卡片。

### 2.3 报告的标准页面与内容

学术研究通用 **IMRaD 结构**（Introduction / Methods / Results / Discussion），可按研究类型取舍——实证研究偏重方法与结果，综述偏重文献脉络。

**学术报告不追求"把所有内容毫无保留展露"**，这跟投研、咨询不一样。重点是把**基础理念、文献脉络、研究设计**讲清楚，再**做好总结**；大量原始推导、数据过程、文献细节都留给论文正文和附录，PPT 只呈现结论和关键证据。

下面 9 类是页面骨架参考，每一页只写**内容要讲什么**，具体的布局样式见 2.4。

| 页面                               | 内容要讲什么                                                                                                                                   |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. 封面页**                | 中文论文题目、英文长 title、副标（学位论文 / 开题答辩 / 中期检查）、作者、导师、单位、日期；不放图表、不放数据。                               |
| **2. 目录页**                | 3-6 个章节编号 + 中文章节名；可配英文名。                                                                                                      |
| **3. 研究背景与问题页**      | 为什么研究这个、现有的痛点或争议、本研究要回答的核心问题。核心问题最好能被质疑、能被验证，不写成中性陈述。                                     |
| **4. 文献综述页**            | 已有研究做到了哪一步、分成几条脉络、各自的代表作与局限、共同的空白在哪。**结尾一句**：现有研究集中在 X、对 Y 关注不足，本研究从 Y 切入。 |
| **5. 研究问题与目标页**      | 把第 3 页的"大问题"拆成 2-3 个可验证的子问题（Q1/Q2/Q3）；对应 2-3 个研究目标。目标要具体可考核，不写"提升效果""深入研究"这类虚词。            |
| **6. 技术路线 / 研究方法页** | 整体技术路线分几个阶段、每个阶段做什么、阶段间怎么衔接；关键方法选型与理由（为什么用这个方法不用别的）。理工科可附关键公式或样本量表。         |
| **7. 研究结果页**            | 发现了什么——**客观呈现，不做解读**。关键数据、关键图表、关键对比，附图下的客观结果说明。                                               |
| **8. 讨论页**                | 结果意味着什么、与已有研究一致还是冲突、为什么会这样；最后回扣第 3 页的研究问题。                                                              |
| **9. 结论与展望页**          | 结论 3-5 条（对应研究问题）、**研究局限**（诚实列出，不藏起来）、后续方向。                                                              |
| **10. 参考文献页**           | 文献列表，每条前面带**方括号序号**（`[1]` `[2]` `[3]`...），序号与正文中的引用一一对应。字号可小（10-11pt），可读即可。**不编造文献**——这是红线。详细格式见 2.4.6。                                                                    |

### 2.4 可参考的布局与视觉骨架

学术报告的视觉基调是**规整、对称、克制**——有点"古早老土"的感觉。规整感来自母版的稳定和布局的对齐，不是来自花哨。

#### 2.4.1 母版骨架（全篇统一，不要每页都变）

- **顶部深蓝标题条**：高 60-80px，深蓝实色（见 §1.2 配色）。左侧放页面主标题（白色，32-40px Bold）；右侧放章节序号 + 英文章节名（如 `01 · Industry Landscape`），字号 16-18px。
- **底部页脚**：高约 20px，灰色 14px。左侧放论文题目 + 答辩/汇报名称；右侧放页码（如 `04 / 18`）。
- **封面、目录、章节扉页、封底（结束页）、感谢页一律不加顶条和页脚**（用户明确要求除外）；其余所有内容页都要带上，锁定同一样式。

#### 2.4.2 可参考的内容布局

下面是几种学术报告常用的页面布局，不同页面可以从里面挑选或组合。**对齐规整是底线，不要错落**。

| 布局                                  | 适用页面                           | 结构描述                                                                                                                                                                                                  |
| ------------------------------------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **信息横幅 + 主体**             | 几乎所有内容页                     | 顶条下方加一条**深蓝色横幅**（或浅底 + 深蓝边框），里面放一个 kicker（如「关键观察」「综述问题」「路线设计」「研究目标」）+ 一句话问题或论断。横幅下方是本页主体内容。这是学术 PPT 最常用的开场器。 |
| **三栏并列卡片**                | 文献综述（三条脉络）、研究目标三条 | 三张等宽等高卡片横向排列，白底 + 灰色描边（**不要底色填充**）。每张卡顶部有编号（Ⅰ/Ⅱ/Ⅲ 或 ①②③）+ 小标题 + 时间或领域标签；中段是 3-5 条要点；底部放代表文献或关键数据。                       |
| **左右两区（6:4 或 5:5）**      | 研究问题 vs 研究目标、方法 vs 结果 | 左右两个大块，每块内部可以再分 2-3 个小区。两区可以用竖线或留白分隔；两区高度严格对齐。                                                                                                                   |
| **阶段流程链**                  | 技术路线、研究方法                 | 顶部一行放 3-6 个阶段卡片（白底描边 + 蓝色小标题 + 要点），中间用箭头或横线连接；下方放一条**阶段输出条**（浅蓝底），再下方用虚线表示滚动迭代或反馈闭环。                                           |
| **2×2 / 2×3 关键词矩阵**      | 文献脉络、技术维度、研究创新点     | 2 行 2 列或 2 行 3 列的方格，每格一个编号 + 关键词 + 一句解释。所有格子等宽等高。                                                                                                                         |
| **大图配文（图 50% / 文 50%）** | 研究背景、实验装置、结果示例       | 左半图、右半文；或上图下文。文字区包含小标题 + 2-3 行说明 + 底部结论条。                                                                                                                                  |
| **KPI 三联数**                  | 研究结果、关键数据总结             | 一行三个巨数字（72-120px Bold 深蓝），每个数字下方跟一行说明（16-20px）。适合把核心数据从正文里拎出来强调。                                                                                               |
| **文献对比表**                  | 文献综述、结果对比                 | 表格列固定（研究 / 方法 / 结论 / 局限 或 已有研究 / 本研究 / 是否一致）。表格**透明底、无行填充色**，重点行用**加粗**或**上下边框线**标记。                                                                 |
| **底部结论条**                  | 几乎所有正文页                     | 页面最下方一条浅底横条（或细边框条），放一句话结论或整页要点——**让读者带着一句话走**。                                                                              |

#### 2.4.3 组件与装饰（克制使用）

- **编号标签**：Ⅰ/Ⅱ/Ⅲ 或 ①②③ 或 Q1/Q2/Q3——同一组用同一种，不混用。
- **深蓝实色卡**：全篇总共不超过 3 张（通常用于信息横幅或关键结论），多卡并列页**禁用**深蓝实色，不然视觉过重。
- **图表**：主图占 50% 以上，用 `chart`（折线/柱/箱线/散点，不用饼图）；原生 chart 画不了的（时间轴节点、组合图）用 `svg` 手绘。
- **公式与代码**（理工科）：公式用 `math` 独立成块，右对齐编号；伪代码用 `codeblock`，字号比正文小一号，只放关键片段。
- **禁用**：3D 字、艺术字、空心字、烟花、印章、金装饰、人物大头照、营销插画、彩虹渐变。

#### 2.4.4 密度与留白

- 内容页主体区铺满宽度（≈1200px），**不要让元素挤在中央 60% 里**。
- 卡片填充率 ≥80%，不要用空白撑高卡片——内容撑不满就换布局，不要留大段空白。
- 并列的多卡**顶边底边严格对齐**，高度差 ≤8px；对齐规整是学术感的来源。
- 文字对比度 ≥4.5:1；深蓝底必须配白字，白底配深蓝或深灰。

#### 2.4.5 关键信息的着色强调

学术报告的**重点数据、关键论点、核心发现**必须通过**视觉强调**让听众一眼抓到——不要指望平铺直叙的正文能被看进去。强调手段按优先级：

1. **字号放大**：关键数字（样本量、准确率、显著性、增长率等）单独拎出来做 **KPI 巨数字**（64-96px Bold），比正文大 3-4 倍
2. **颜色高亮**：关键词或关键数据用**警示红** `#D9534F` 或 **主蓝** `#1E4FA8` 加粗；一般名词和过渡性文字保持正文色 `#1A2230`
3. **高亮底条**：核心论点或关键结论用**浅蓝底条** `#E8EFF8`（或浅黄 `#FFF8E1`）打底，字保持正文色——这是最接近真实学术 PPT 的"马克笔画线"效果

**什么内容必须被强调**：

- **样本量 / 实验规模**（如 `N = 5469`、`覆盖 123 所高校`）
- **核心指标数值**（如 `准确率 92.3%`、`p < 0.001`、`相关系数 0.78`）
- **关键发现句**（如"本研究首次发现 X 与 Y 存在显著负相关"）
- **本研究 vs 已有研究的差异点**（文献对比表里的"本研究"行）
- **研究局限的边界条件**（避免被误读）

**几条纪律**：

- **强调是稀缺资源**。一页里红色或高亮底条总共不超过 **2-3 处**，多了就等于没有强调
- **不用整行底色填充表格**——重点行用加粗 + 上下边框线标记，表格本体保持透明（见 2.4.3）
- **不要只靠加粗**——学术 PPT 里加粗太常见，光靠加粗抓不住注意力。颜色、字号、底条至少配合其一

#### 2.4.6 参考文献格式

参考文献页**不是装饰性收尾**——是学术专业度的直接体现。格式必须规范。

**序号规则**：

- 每条文献前加方括号序号 `[1]` `[2]` `[3]`...，数字右对齐或左对齐都可以，整页统一
- 序号要与**正文中的引用一一对应**。正文里引用某文献时写成"...已有研究表明 [3]"或"Smith et al. (2020) 的方法 [5] 表明..."
- 文献太多时按**正文首次出现顺序**编号（IEEE 风格）；或按**作者姓氏字母 / 发表年份**排序（APA / GB/T 7714 风格）——两种选一种，不混用

**常见引用格式**（选一种贯穿全文）：

| 格式 | 适用学科 | 示例 |
| --- | --- | --- |
| **GB/T 7714**（国标） | 中文论文、国内高校答辩默认 | `[1] 张三, 李四. 深度学习在金融预测中的应用[J]. 计算机学报, 2023, 46(5): 1023-1045.` |
| **APA 第 7 版** | 心理学、教育学、社会科学 | `[1] Smith, J., & Chen, L. (2023). Deep learning in financial forecasting. Journal of AI Research, 46(5), 1023-1045.` |
| **IEEE** | 理工科、计算机、工程 | `[1] J. Smith and L. Chen, "Deep learning in financial forecasting," J. AI Res., vol. 46, no. 5, pp. 1023-1045, 2023.` |
| **MLA 第 9 版** | 文史哲、人文学科 | `[1] Smith, John, and Lily Chen. "Deep Learning in Financial Forecasting." Journal of AI Research, vol. 46, no. 5, 2023, pp. 1023-1045.` |
| **Chicago**（Notes-Bibliography / Author-Date） | 历史学、艺术史、部分社科 | `[1] John Smith and Lily Chen, "Deep Learning in Financial Forecasting," Journal of AI Research 46, no. 5 (2023): 1023-1045.` |

**几条纪律**：

- **按用户所在学科 / 组织的习惯选格式**。中文论文优先 GB/T 7714，理工科优先 IEEE，不要默认都用 APA
- **期刊名 / 书名用斜体**（手动做斜体，不要靠字体区分）
- **DOI 或 URL 可以附在条目最后**，字号比正文再小一号（10pt）
- **一页放不下**就分页，不要缩小字号到不可读；每页顶部重复"参考文献（续）"
- **按姓氏字母顺序**排时，中文作者按**拼音首字母**排
- **不编造**——这是红线。宁可少列、宁可标"文献省略见论文正文"，也不能生造

## 三、完成检查

**内容层面**：研究问题是否清楚？文献引用是否真实可查？方法与结果是否对应？结果页是客观描述还是混入了解读？讨论有没有回应研究问题？局限是否诚实？有没有编造的公式/数据/引用？

**视觉层面**：组织风格（色、Logo、字体）是否沿用一致？字体字号阶梯是否稳定？图表标签和引用来源是否可读？**表格是否误加了底色**（应为透明）？

**对齐与密度**：通用规则见 `design-principle.md`——区块左边缘同一竖线、并列区块顶/底齐平、同级间距相等、无夹空洞的留白。
