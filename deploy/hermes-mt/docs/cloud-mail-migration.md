# 云端邮箱迁移

## 已实现范围

复用桌面“我的邮箱”页面、沃邮箱授权码协议、IMAP/SMTP 实现、操作输入校验和每日 50 封发送限额。
页面支持开通、停用、收件/发件文件夹、邮件搜索与分页、详情、标记已读、删除和附件下载。
发送、回复和转发沿用桌面的对话入口，由用户实例的 `Agent-Mail` MCP 执行。
未开通时 MCP 默认关闭；开通后新建会话生效，停用后已有会话的调用也会被拒绝，不修改当前会话的提示词。

## 身份和运行位置

- 浏览器通过固定 `/__entry/mail` 携带当前 MaaS Bearer 和 HttpOnly session cookie。
- 入口只使用登录证明中的手机号生成 `<手机号>@wo.cn`，忽略页面自报手机号、用户 ID 和邮箱。
- 开通使用桌面既有授权码接口，并在实例中核验 IMAP、SMTP；完整 MaaS token 不进入实例。
- 实例按当前 Hermes Home 运行邮箱 Node worker，页面与 MCP 共用同一账号状态和供应商协议。
- 入口阻止浏览器直达内部配置接口和 MCP 地址。附件仅通过当前账号实例的固定下载路由提供。

邮箱授权码加密保存于当前 Home 的 `agent-mail/state.enc`，密钥同目录、文件权限 600；
和桌面一样，它属于当前用户实例的本地凭据，并非对该实例内用户代码隐藏的独立凭据保险库。
停用保留授权用于重新启用。退出网页登录不会删除已有邮箱授权；停止工具访问需在页面停用邮箱。

## 持久化与实例暂停

开通、停用后复用技能市场的状态检查点逻辑，Cube 确认归档后才返回成功，Docker 使用原用户卷。
保存未确认时返回明确错误，不把状态变更误报为已持久化。重试启停不会发送邮件。
发送计数直接保存于账号工作区卷的 `.agent-mail`，固定跟随账号而非可修改的项目 cwd；
附件写入卷内 `uploads/mail-attachments`，目前单附件上限 10 MiB。
模板升级保留用户对 MCP 的启停选择，不把已开通邮箱重置为未开通。

实例暂停期间，邮件仍由沃邮箱保存；打开页面或唤醒后再查询。本轮不包含后台实时收信推送。
不自动重试发送、回复或转发；结果不确定时先检查“发信记录”，避免重复邮件。

## 构建与部署

`node apps/desktop/scripts/build-cloud-mail.mjs` 复用已准备的 OpenConnector 依赖生成：

- `plugins/cloud_mail/worker.mjs`：实例私有 Node 协议 worker。
- `plugins/cloud_mail/tools.json`：从同一份供应商定义生成的 MCP 契约。

这些产物随代码提交，云端部署不临时安装 OpenConnector 依赖。
入口的授权码处理复用 `cloud-drive-worker.mjs`，由现有 `build-cloud-drive.mjs` 生成。
入口、前端和包含 `plugins/cloud_mail` 的实例模板需一起更新：

```bash
bash deploy.sh all --branch cloud-adaptation
```

上线验收：手机号登录 → 我的邮箱开通 → 查看邮件及附件 → 新建会话发送测试邮件 →
检查已发送及计数 → 停用后验证旧会话无法调用 → 实例升级/恢复后核验启停状态与计数。

本地测试覆盖真实 Entry/PG、实例 HTTP、MCP 发现分发、A→B→A 范围隔离、状态归档恢复，
并用本机 SMTP 服务验证共享邮件协议。沃邮箱线上账号开通及网络连通仍需部署后验收。
